# Milestone v10.0: Attribute System

**Status:** SHIPPED 2026-03-28
**Phases:** 93-99

## Overview

Complete the builtin attribute pipeline (semantic effects + argument serialization) and add user-defined attributes with a runtime query API for host-driven game wiring.

## Milestone Summary

**Key Decisions:**
- Blob encoding is the dependency-graph root — every feature depends on round-trip encode/decode
- [Conditional] elision at emit time only — args still type-check when call is elided
- ModuleAttributeView (not &Domain) as pre-load callback argument — bounded from day one
- Builtin name reservation via DefId origin in collector pass, not bare string matching
- KwAttribute as real keyword (not contextual), placed in Declaration section
- ATTR_OWNER_KIND_DECL=3 distinguishes attribute declarations from applications
- find_attrs_for_entry duplicated in env_build.rs to keep emit module boundary clean
- validate_speakers detects Entity.getOrCreate<Name>() hoisted let pattern
- ModuleAttributeView::new is pub(crate) — only RuntimeBuilder creates instances

**Issues Resolved:**
- RES-09 Speaker validation stub completed (long-standing tech debt from v3.0)
- AttributeDefRow.value=0 placeholder replaced with actual blob encoding
- validate_speakers() stub filled with full E0007/E0003 diagnostics

**Technical Debt Incurred:**
- UATTR-04 E0008 has no dedicated LSP E2E test (compiler unit test covers it)
- 2 dead code warnings in lookup.rs (find_extern_struct_decl, find_extern_class_decl)

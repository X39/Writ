# Requirements: Writ Compiler

**Defined:** 2026-03-28
**Core Value:** Correct, spec-compliant implementation at every layer — lowering matches Section 28 exactly, runtime matches the IL spec exactly — structured so each layer can be extended independently.

## v11.0 Requirements

Requirements for Runtime Reflection milestone. Each maps to roadmap phases.

### Spec & IL Foundation

- [x] **SPEC-01**: Reflection type system defined in new language spec section (Type, FieldInfo, MethodInfo, ParameterInfo, AttributeInfo, ContractInfo)
- [x] **SPEC-02**: typeof(expr) semantics defined — static type query returning Type, distinct from get_type() dynamic query
- [x] **SPEC-03**: Reflectable contract defined — auto-implemented on all user-defined types, single get_type() method
- [x] **SPEC-04**: Dynamic invocation rules defined — MethodInfo.invoke(), FieldInfo.set() mutability enforcement, Type.construct() lifecycle hook dispatch
- [x] **SPEC-05**: TypeOf opcode assigned in §4.2 opcode table
- [x] **SPEC-06**: format_version bumped to 4 in spec
- [x] **SPEC-07**: any-at-boundaries resolved — BOX/UNBOX coercion approach for reflection API parameters/returns
- [x] **SPEC-08**: Generic reflection scope documented — what type_args() promises for static vs runtime-queried types

### Builtin Reflection Types

- [x] **TYPE-01**: Type builtin class in writ-runtime virtual module with name, kind, namespace fields
- [x] **TYPE-02**: FieldInfo builtin class with name, declared_type, is_mutable fields
- [x] **TYPE-03**: MethodInfo builtin class with name, parameters, return_type fields
- [x] **TYPE-04**: ParameterInfo builtin class with name, declared_type fields
- [x] **TYPE-05**: AttributeInfo builtin class with name, args fields
- [x] **TYPE-06**: ContractInfo builtin class with name, type fields
- [x] **TYPE-07**: Reflectable contract (contract 19) with get_type() -> Type method
- [x] **TYPE-08**: Primitive get_type() intrinsics for Int, Float, Bool, String

### Read-Only Introspection

- [x] **REFL-01**: typeof(expr) returns Type for any type expression (structs, classes, enums, entities, contracts, primitives)
- [x] **REFL-02**: expr.get_type() returns runtime dynamic Type via Reflectable contract dispatch
- [x] **REFL-03**: Type.fields() returns Array of FieldInfo for all pub fields
- [x] **REFL-04**: Type.methods() returns Array of MethodInfo for all pub methods
- [x] **REFL-05**: Type.attributes() returns Array of AttributeInfo (integrates with v10.0 attribute query system)
- [x] **REFL-06**: Type.contracts() returns Array of ContractInfo for all implemented contracts
- [x] **REFL-07**: Type.implements(contract) returns bool for runtime capability check
- [x] **REFL-08**: FieldInfo.get(instance) returns field value dynamically (boxed)
- [x] **REFL-09**: Type equality by identity — typeof(T) == typeof(T) is true, interned per TypeDef

### Dynamic Invocation

- [x] **DYN-01**: FieldInfo.set(instance, value) writes field dynamically with runtime mutability enforcement (crash on let-field write)
- [x] **DYN-02**: MethodInfo.invoke(instance, args) invokes method dynamically on current task stack with arg count/type validation
- [ ] **DYN-03**: Type.construct(args) creates instance dynamically with on_create lifecycle hook dispatch
- [x] **DYN-04**: Dynamic invocation correctly participates in cooperative scheduling (defer runs on unwind, spawn yields)

### Generic Reflection

- [x] **GEN-01**: Type.is_generic returns bool indicating whether the type has generic parameters
- [x] **GEN-02**: Type.type_args() returns Array of Type for bound generic arguments (statically-known instantiations)
- [x] **GEN-03**: Per-member attribute access — MethodInfo.attributes() and FieldInfo.attributes() return AttributeInfo arrays
- [x] **GEN-04**: Generic reflection limitations documented in spec for runtime-queried types

### Compiler Pipeline

- [x] **COMP-01**: typeof(expr) lowered to AstExpr::TypeOf AST node (not a function call)
- [x] **COMP-02**: TypeOf instruction emitted with compile-time type index baked into instruction
- [x] **COMP-03**: Reflectable auto-impl emitted per user TypeDef interleaved in main codegen pass
- [x] **COMP-04**: BOX/UNBOX coercion auto-inserted at reflection API boundaries
- [x] **COMP-05**: TyKind::ReflectionType added to type checker for reflection builtin types

### Runtime

- [x] **RT-01**: ReflectionIndex with lazy FxHashMap caches for Type/FieldInfo/MethodInfo heap objects
- [x] **RT-02**: GC root registration for reflection singleton objects (permanent roots, not freed by collection)
- [x] **RT-03**: TypeOf opcode dispatch in VM main loop
- [x] **RT-04**: All reflection IntrinsicId arms dispatched correctly (28+ new variants)
- [x] **RT-05**: Unified AttributeIndex shared with v10.0 ModuleAttributeView

### LSP

- [x] **LSP-01**: Standard diagnostics for reflection type usage (type errors, missing methods)
- [x] **LSP-02**: Hover display for typeof() and reflection type members

## Future Requirements

### Deferred to v12+

- **DFUT-01**: writ-std reflection utilities (debug printer, generic factory, command dispatcher)
- **DFUT-02**: String-based type lookup (Type.for_name()) — explicit anti-feature, security risk

## Out of Scope

| Feature | Reason |
|---------|--------|
| String-based type lookup (Type.for_name()) | Serialization injection attack vector; host controls type resolution |
| Access to non-pub fields via reflection | Script visibility is host contract; breaking it via reflection destroys host trust model |
| Dynamic code generation / IL emit at runtime | Separate milestone; requires full assembler + loader in VM |
| Reflection on extern declarations | Extern functions are host-registered; enumerating them is a capability-discovery surface |
| Automatic Into<string> derivation via reflection | 10-100x slower than compiled impl; defer to writ-std debug utility |
| Reflection-specific LSP features | Standard diagnostics only this milestone; reflection-aware go-to-def in future |

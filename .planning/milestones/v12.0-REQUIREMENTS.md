# Requirements: Writ Compiler

**Defined:** 2026-03-28
**Core Value:** Correct, spec-compliant implementation at every layer — lowering matches Section 28 exactly, runtime matches the IL spec exactly — structured so each layer can be extended independently.

## v12.0 Requirements

Requirements for tech debt cleanup. Each maps to roadmap phases.

### Runtime Bugs

- [x] **RT-01**: Closure capture list populates captured variables correctly (TYPE-12 fix — closures referencing outer variables execute with correct captured values)

- [x] **RT-03**: `::choice` with `fn() {}` lambda arguments serializes without UnexpectedEof error

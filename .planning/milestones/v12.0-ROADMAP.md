## Phase Details

### Phase 109: TYPE-12 Closure Capture Fix
**Goal**: Closures that reference outer-scope variables execute with the correct captured values
**Depends on**: Phase 108
**Requirements**: RT-01
**Success Criteria** (what must be TRUE):
  1. A closure that captures a local variable from the enclosing scope returns the correct value when invoked
  2. Multiple closures capturing different outer variables each see their own captured values
  3. A closure passed as a function argument executes with its captured environment intact
  4. All existing closure-related golden tests and runtime tests continue to pass
**Plans**: 1 plan
Plans:
- [x] 109-01-PLAN.md — Capture analysis in type checker + capture-aware lambda body emission + golden test

### Phase 110: Runtime Bug Fixes
**Goal**: Core runtime execution produces correct results for string length and choice serialization
**Depends on**: Phase 109
**Requirements**: RT-02, RT-03
**Success Criteria** (what must be TRUE):
  1. `s.len()` on a string value returns the number of bytes in the string, not a heap slot index
  2. A dialogue function using `::choice` with `fn() {}` lambda arguments assembles and runs without UnexpectedEof serialization error
  3. Multi-function modules containing choice lambdas load and execute correctly end-to-end
**Plans**: 1 plan
Plans:
- [x] 110-01-PLAN.md — E2E test for s.len() + fix ::choice serialization orphaned body matching + regression tests

### Phase 111: Assembler Completeness
**Goal**: The text assembler handles all directives that the disassembler can emit, with correct type blob offsets
**Depends on**: Phase 110
**Requirements**: ASM-01, ASM-02
**Success Criteria** (what must be TRUE):
  1. `.export`, `.extern_fn`, `.component`, `.locale`, and `.attribute` directives parse and assemble without error
  2. A module assembled from disassembler output round-trips to identical binary (assemble → disassemble → re-assemble produces same bytes)
  3. Register type blob offsets in assembled output are real byte positions, not 0 placeholders
  4. Existing assembler round-trip tests continue to pass
**Plans**: 1 plan
Plans:
- [x] 111-01-PLAN.md — Lexer/AST/parser/disassembler directive parity + assembler wiring + register type blob fix + round-trip tests

### Phase 113: LSP Completions Refactor
**Goal**: Option/Result namespace completions are driven by the type environment rather than hardcoded variant lists
**Depends on**: Phase 112
**Requirements**: LSP-01
**Success Criteria** (what must be TRUE):
  1. Typing `Option::` in the editor triggers completions sourced from type_env enum variants, not a hardcoded list
  2. Typing `Result::` produces completions sourced from type_env
  3. Adding a user-defined enum to a file causes its variants to appear in `::` completions without any special-casing
  4. Existing LSP completion tests pass after the refactor
**Plans**: 1 plan
Plans:

### Phase 114: DAP Fixes
**Goal**: The debug adapter attributes source locations correctly per frame and handles dialogue string interpolation
**Depends on**: Phase 113
**Requirements**: DAP-01, DAP-02

  3. A dialogue text line containing `$"Hello {name}!"` interpolation executes through lower_fmt_string and produces the correct output string
  4. Existing DAP integration tests pass after both fixes

<objective>
Implement the compiler pipeline for the leveled `log::` namespace: resolver injection of 5 synthetic ExternFn DefIds, TypeEnv FnSig injection, check_call two-segment path handling, and emitter ExternDef row injection.

Purpose: This is the core compiler infrastructure that makes `log::trace(msg)` through `log::error(msg)` compile to CALL_EXTERN instructions. Without this, no log-level call can be resolved, type-checked, or emitted.

Output: All 5 `log::level(msg)` calls compile through the full pipeline (resolve -> check -> emit), producing CALL_EXTERN with the correct ExternDef token. The old `log(msg)` form naturally fails resolution.
</objective>

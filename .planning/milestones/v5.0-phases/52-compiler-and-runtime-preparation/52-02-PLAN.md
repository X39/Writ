<objective>
Add debug hooks to RuntimeHost and SuspendReason to Task for DAP breakpoint/stepping control.

Purpose: The DAP server (Phase 55) needs two capabilities: (1) the ability to break execution at specific instructions via a host callback, and (2) the ability to distinguish why a task suspended (breakpoint vs host request vs debug step). This plan adds both without affecting production (NullHost/CliHost) performance.

Output: RuntimeHost trait with debug hook methods, DebugAction enum for stepping control, SuspendReason enum on Task, and VM dispatch integration that calls hooks only when debug_enabled() is true.
</objective>

    **Step 1 — Source location lookup helper in dispatch/mod.rs:**

    Add a helper function that, given a module, method index, and PC, finds the corresponding source location from `source_spans`:
    ```rust
    /// Look up the source line/col for a given PC in a method's source span table.
    /// Returns (0, 0) if no source span covers this PC.
    fn lookup_source_location(module: &LoadedModule, method_idx: usize, pc: u32) -> (u32, u16) {
        if method_idx >= module.module.method_bodies.len() {
            return (0, 0);
        }
        let spans = &module.module.method_bodies[method_idx].source_spans;
        // Find the last span with pc <= target_pc (spans sorted by pc)
        let mut best = (0u32, 0u16);
        for span in spans {
            if span.pc <= pc {
                best = (span.line, span.column);
            } else {
                break;
            }
        }
        best
    }
    ```

    **Step 2 — Debug hook in execute_one:**

    At the top of `execute_one`, after fetching the frame but before fetching the instruction, insert the debug hook guard:
    ```rust
    if host.debug_enabled() {
        let method_idx_usize = frame.method_idx; // get from frame
        let pc = frame.pc as u32;
        let (line, col) = lookup_source_location(module, method_idx_usize, pc);
        let action = host.before_instruction(task.id, method_idx_usize as u32, pc, line, col);
        match action {
            DebugAction::Continue => {},
            DebugAction::Break => {
                task.suspend_reason = Some(SuspendReason::Breakpoint {
                    method_idx: method_idx_usize as u32, pc, line, col
                });
                task.state = TaskState::Suspended;
                return ExecutionResult::DebugSuspend;
            },
            DebugAction::StepOver | DebugAction::StepInto | DebugAction::StepOut => {
                task.suspend_reason = Some(SuspendReason::DebugStep {
                    mode: action, method_idx: method_idx_usize as u32, pc, line, col
                });
                task.state = TaskState::Suspended;
                return ExecutionResult::DebugSuspend;
            },
            DebugAction::Disconnect => {
                // Host requested disconnect — continue without debug
                // The host should set its own internal debug_enabled to false
                // so subsequent calls to debug_enabled() return false
            },
        }
    }
    ```

    Add a new `DebugSuspend` variant to `ExecutionResult`:
    ```rust
    /// Task suspended for debug (breakpoint or step). Unlike Suspended(RequestId),
    /// this does not require a host response to resume — the DAP server controls resume.
    DebugSuspend,
    ```

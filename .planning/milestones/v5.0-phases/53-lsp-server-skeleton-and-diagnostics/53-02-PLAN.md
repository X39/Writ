<task type="auto">
  <name>Task 2: Create TextMate grammar for Writ syntax highlighting</name>
  <files>writ-vscode/syntaxes/writ.tmLanguage.json</files>
  <action>
Create `writ-vscode/syntaxes/writ.tmLanguage.json` with comprehensive Writ syntax coverage.

The grammar must cover these patterns (in priority order):

1. **comments** — Both line (`//`) and block (`/* */`). Block comments are nestable in Writ spec but TextMate does not support nesting -- use begin/end for the outermost level. Scope: `comment.line.double-slash.writ`, `comment.block.writ`.

2. **strings** — Three forms:
   - Triple-quoted raw strings `"""..."""`: scope `string.quoted.triple.writ`. MUST come before double-quoted to avoid greedy match.
   - Formattable strings `$"...{expr}..."`: scope `string.quoted.double.formattable.writ` with `meta.interpolation.writ` for `{...}` blocks and `constant.character.escape.writ` for `\\`.
   - Regular strings `"..."`: scope `string.quoted.double.writ` with escape sequences.

3. **keywords** — Three groups:
   - Declaration keywords: `fn|dlg|struct|enum|contract|impl|entity|component|namespace|extern|using` as `keyword.declaration.writ`
   - Control flow: `if|else|match|for|while|in|return|break|continue|try` as `keyword.control.writ`
   - Other keywords: `let|mut|const|global|pub|priv|void|self|true|false|null|new|on|use|spawn|detached|join|cancel|defer|atomic` as `keyword.other.writ`
   - Primitive types: `int|float|bool|string|char` as `storage.type.primitive.writ`

4. **numbers** — Integer and float literals: `\b[0-9][0-9_]*(\.[0-9][0-9_]*)?\b` as `constant.numeric.writ`. Also hex `0x[0-9a-fA-F_]+` and binary `0b[01_]+`.

5. **dialogue-blocks** — Speaker attribution `@SpeakerName` as `entity.name.tag.speaker.writ` (the @ plus identifier). Dialogue code escape `$` before `{`, `if`, `match`, `choice` as `keyword.operator.dialogue-escape.writ`.

6. **attributes** — `[...]` blocks as `meta.attribute.writ`, with string contents inside highlighted.

7. **operators** — Path separator `::`, return arrow `->`, range operators `..=` and `..`, null-propagation `?.`, standard operators `+`, `-`, `*`, `/`, `%`, `=`, `<`, `>`, `!`, `&`, `|`, `^`, `?` as `keyword.operator.writ`.

8. **function-calls** — Match identifier followed by `(` to scope the identifier as `entity.name.function.writ`. Pattern: `\b([a-zA-Z_][a-zA-Z0-9_]*)\s*\(` with capture 1 as function name.

9. **type-names** — Match PascalCase identifiers (starting with uppercase) as `entity.name.type.writ`. Pattern: `\b([A-Z][a-zA-Z0-9_]*)\b`.

Structure the JSON with a top-level `patterns` array that includes each repository pattern, and a `repository` object with named pattern groups. Use `\b` word boundaries on keyword matches to prevent partial matches.

The `scopeName` MUST be `"source.writ"` to match package.json.

Note: Semantic highlighting (Phase 54, DIFF-01) will refine entity names, component types, and dialogue speakers beyond what TextMate can distinguish. This grammar provides good-enough structural highlighting.
  </action>

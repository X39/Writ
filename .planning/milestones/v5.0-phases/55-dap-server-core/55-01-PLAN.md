**Create `writ-dap/src/breakpoints.rs`:**

```rust
use std::collections::HashMap;
use writ_module::module::{Module, SourceSpan};

/// A verified breakpoint with its resolved IL address.
#[derive(Debug, Clone)]
pub struct ResolvedBreakpoint {
    pub id: u32,
    pub line: u32,           // actual line (may differ from requested if snapped)
    pub method_idx: usize,
    pub pc: u32,
}

/// Maps source file lines to IL instruction addresses using SourceSpan data.
pub struct BreakpointTable {
    /// All valid breakpoint lines from the module's SourceSpan data.
    /// Maps line -> Vec<(method_idx, pc)> (a line may appear in multiple methods).
    line_index: HashMap<u32, Vec<(usize, u32)>>,
    /// Active breakpoints: breakpoint_id -> ResolvedBreakpoint
    active: HashMap<u32, ResolvedBreakpoint>,
    /// Reverse lookup for before_instruction: (method_idx, pc) -> breakpoint_id
    pc_lookup: HashMap<(usize, u32), u32>,
    next_id: u32,
}
```

Methods on BreakpointTable:
- `new(module: &Module) -> Self` — build `line_index` by iterating all `method_bodies[i].source_spans` and mapping `span.line -> (i, span.pc)`. Use the first pc per line per method (earliest instruction on that line).
- `set_breakpoints(lines: &[u32]) -> Vec<ResolvedBreakpoint>` — for each requested line, find exact match in `line_index` or snap to nearest valid line >= requested. Create ResolvedBreakpoint entries, update `active` and `pc_lookup`. Clear any previously set breakpoints not in the new set. Return the resolved breakpoints (DAP needs these for the response).
- `lookup(&self, method_idx: usize, pc: u32) -> Option<u32>` — check `pc_lookup` for a breakpoint_id at this (method_idx, pc).
- `clear_all(&mut self)` — remove all breakpoints.

**Create `writ-dap/src/debug_host.rs`:**

```rust
use std::collections::HashMap;
use writ_runtime::{
    DebugAction, HostRequest, HostResponse, LogLevel, RequestId, RuntimeHost, Value, TaskId,
    GcStats,
};
use crate::breakpoints::BreakpointTable;

/// Why the debugger stopped.
#[derive(Debug, Clone)]
pub enum StopReason {
    Breakpoint(u32),  // breakpoint id
    Step,
    Entry,            // initial launch stop
    Pause,
}

/// Stepping mode state machine.
#[derive(Debug, Clone)]
enum StepMode {
    None,
    StepOver { origin_depth: usize, origin_line: u32, origin_method: u32 },
    StepInto { origin_line: u32, origin_method: u32 },
    StepOut { origin_depth: usize },
}

pub struct DebugHost {
    pub breakpoints: BreakpointTable,
    step_mode: StepMode,
    call_depths: HashMap<TaskId, usize>,
    pub pending_stop: Option<StopReason>,
    debug_active: bool,
}
```

DebugHost implements RuntimeHost:

- `debug_enabled(&self) -> bool` — returns `self.debug_active`
- `before_instruction(task_id, method_idx, pc, source_line, source_col) -> DebugAction`:
  1. Check breakpoints: `if let Some(bp_id) = self.breakpoints.lookup(method_idx as usize, pc)` -> set `pending_stop = Some(StopReason::Breakpoint(bp_id))`, return `DebugAction::Break`
  2. Check stepping mode:
     - `StepMode::StepOver { origin_depth, origin_line, origin_method }`: get `depth = self.call_depths.get(&task_id).copied().unwrap_or(0)`. If `depth <= origin_depth && (source_line != origin_line || method_idx != origin_method as u32)` -> stop. This ensures we skip instructions on the same line but stop when line changes at same depth.
     - `StepMode::StepInto { origin_line, origin_method }`: If `source_line != origin_line || method_idx != origin_method as u32` -> stop.
     - `StepMode::StepOut { origin_depth }`: If `depth < origin_depth` -> stop.
  3. Return `DebugAction::Continue`
- `on_function_enter(task_id, method_idx)`: increment `call_depths[task_id]` (insert 1 if absent, else +1)
- `on_function_exit(task_id, method_idx)`: decrement `call_depths[task_id]` (saturating subtract)
- `on_request(id, req) -> HostResponse`: auto-confirm all requests with default values (same as NullHost pattern — the DAP server does not implement a full game host)
- `on_log(level, message)`: write to stderr as `[DAP] {level:?}: {message}`

Additional methods on DebugHost (not trait methods):
- `new(breakpoints: BreakpointTable) -> Self`
- `set_step_mode(&mut self, mode: StepMode)` — called by DapServer when user issues next/stepIn/stepOut
- `set_step_over(&mut self, task_id: TaskId)` — convenience: reads current depth and line to set StepMode::StepOver
- `set_step_into(&mut self, task_id: TaskId, current_line: u32, current_method: u32)` — sets StepMode::StepInto
- `set_step_out(&mut self, task_id: TaskId)` — convenience: reads current depth to set StepMode::StepOut
- `clear_step(&mut self)` — resets to StepMode::None
- `take_pending_stop(&mut self) -> Option<StopReason>` — takes and returns the pending stop reason
- `current_depth(&self, task_id: TaskId) -> usize` — returns current call depth for a task

Make StepMode, StopReason, and the convenience methods `pub` so DapServer (Plan 02) can use them.

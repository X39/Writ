  <name>Task 2: Create variables.rs with format_value, decode_type_blob, and variablesReference encoding</name>
  <files>writ-dap/src/variables.rs, writ-dap/src/lib.rs</files>
  <behavior>
    - format_value(Value::Void) returns "(void)"
    - format_value(Value::Int(42)) returns "42"
    - format_value(Value::Float(3.14)) returns a float string
    - format_value(Value::Bool(true)) returns "true"
    - format_value(Value::Ref(href)) for a String heap object returns the quoted string
    - format_value(Value::Ref(href)) for a Struct returns "struct(N)" with field count
    - format_value(Value::Ref(href)) for an Array returns "[N elements]"
    - format_value(Value::Entity(eid)) returns "entity#N"
    - format_value(Value::InlineStruct) returns "structN(M)" with type_idx and field count
    - decode_type_blob returns "void"/"int"/"float"/"bool"/"string" for tags 0x00-0x04
    - decode_type_blob returns TypeDef name from module.type_defs for tag 0x10
    - decode_type_blob returns "Array<?>" for tag 0x20
    - decode_type_blob returns "?" for unknown/empty/zero-offset blobs
    - make_variables_ref(0, 0) and unpack roundtrips to (0, 0)
    - make_variables_ref(5, 9) and unpack roundtrips to (5, 9)
    - make_variables_ref(u32::MAX, u32::MAX) and unpack handles large values
  </behavior>
  <action>
Create `writ-dap/src/variables.rs` with these public functions:

1. `pub fn make_variables_ref(task_idx: u32, frame_idx: u32) -> i64` — packs `(task_idx as i64) << 32 | (frame_idx as i64)`.

2. `pub fn unpack_variables_ref(r: i64) -> (u32, u32)` — unpacks `((r >> 32) as u32, (r & 0xFFFFFFFF) as u32)`.

3. `pub fn format_value(val: &Value, module: &Module, heap: &dyn GcHeap) -> String` — match on all Value variants:
   - `Void` -> `"(void)"`
   - `Int(n)` -> `n.to_string()`
   - `Float(f)` -> `format!("{}", f)` (use Display, not fixed precision -- Rust Display for f64 is fine)
   - `Bool(b)` -> `b.to_string()`
   - `Ref(href)` -> call `heap.get_object(*href)` and match:
     - `HeapObject::String(s)` -> `format!("{:?}", s)` (quoted)
     - `HeapObject::Struct { fields }` -> `format!("struct({})", fields.len())`
     - `HeapObject::Array { elements, .. }` -> `format!("[{} elements]", elements.len())`
     - `HeapObject::Delegate { method_idx, .. }` -> `format!("fn@{}", method_idx)`
     - `HeapObject::Enum { tag, .. }` -> `format!("enum(tag={})", tag)`
     - `HeapObject::Boxed(v)` -> `format!("box({})", format_value(v, module, heap))`
     - `Err(_)` -> `"<invalid ref>".to_string()`
   - `Entity(eid)` -> `format!("entity#{}", eid.index)`
   - `InlineStruct { type_idx, fields }` -> `format!("struct{}({})", type_idx, fields.len())`

4. `pub fn decode_type_blob(module: &Module, type_ref_offset: u32) -> String` — if offset is 0, return `"?"`. Call `read_blob(&module.blob_heap, type_ref_offset)`. Match first byte:
   - `0x00` -> `"void"`, `0x01` -> `"int"`, `0x02` -> `"float"`, `0x03` -> `"bool"`, `0x04` -> `"string"`
   - `0x10` if len >= 5 -> read u32 from bytes[1..5] as LE, subtract 1 for 0-based index, look up `module.type_defs.get(row).and_then(|td| read_string(&module.string_heap, td.name).ok()).map(|s| s.to_string()).unwrap_or_else(|| "Type".to_string())`
   - `0x20` -> `"Array<?>"` (nested type decoding not needed for Phase 56)
   - `0x30` -> `"fn"` (function signature)
   - `_` -> `"?"`
   On any `Err` from `read_blob`, return `"?"`.

Import from `writ_runtime::{Value, heap::HeapObject}` and `writ_runtime::gc::GcHeap`. Import from `writ_module::module::Module` and `writ_module::heap::{read_blob, read_string}`.

Add `pub mod variables;` to `writ-dap/src/lib.rs` (after existing module declarations).

Add `#[cfg(test)] mod tests` in variables.rs:
- Test `make_variables_ref`/`unpack_variables_ref` roundtrips for (0,0), (1,5), (100, 999)
- Test `format_value` for Void, Int, Float, Bool (use a stub module + heap -- create `Module::new()` and `BumpHeap::new()`)
- Test `decode_type_blob` for primitives by constructing a minimal blob heap with known tag bytes (build a `Vec<u8>` blob heap with length-prefixed entries, create Module with that blob_heap)

Note on heap for format_value tests: `BumpHeap` implements `GcHeap`. Allocate a string with `heap.alloc_string("hello")`, then call `format_value(&Value::Ref(href), &module, &heap)` and assert the result contains `"hello"`.

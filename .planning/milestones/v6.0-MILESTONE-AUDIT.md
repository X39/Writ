## Cross-Phase Integration Issues

### Issue 1: WARN-02 Broken by Phase 65-03 (CRITICAL)

**From:** Phase 65-03 (`pub` → `pub(crate)` narrowing, commit `f6abe91`)
**To:** Phase 62 WARN-02 requirement (`cargo clippy` exits clean)

Phase 62 achieved zero warnings. Phase 65-03 narrowed `check::infer`, `check::mutability`, and `resolve::scope` from `pub mod` to `pub(crate) mod`. This allowed rustc's dead-code analysis to detect 6 previously-hidden unused items:

1. `check/infer.rs` — `fn resolve_type_to_ty` (never called)
2. `check/mutability.rs` — `fn check_method_mutation` (never called externally)
3. `check/mutability.rs` — `fn find_root_binding` (dead; duplicate exists in check_expr/mod.rs)
4. `resolve/scope.rs` — `ScopeLayer::Locals` variant (never constructed)
5. `resolve/scope.rs` — `LookupResult::BuiltinVariant` variant (constructed only by dead `resolve_value`)
6. `resolve/scope.rs` — `push_locals`, `add_local`, `resolve_value` methods (never called from resolver.rs)

**Fix:** Remove or `#[allow(dead_code)]` these 6 items. Removal preferred — they appear to be leftover scaffolding.

### Issue 2: Dialogue Say Argument Regression (CRITICAL)

**From:** Phase 62-01 (`cargo clippy --fix`, commit `1bb8a46`)
**To:** Test suite (30 failures)

The clippy auto-fix pass renamed `speaker_ref` to `_speaker_ref` in `lower/dialogue.rs`, which also removed it from the emitted `say()` call arguments. This changed the generated code from `say(speaker, text)` to `say(text)` — a semantic behavior change.

**Evidence:**
- `emit_tests::choice_option_emits_externdef` — expects `say(Entity, string)` (2 params), gets `say(string)` (1 param)
- 29 lowering snapshot tests — expected `say(player, "text")`, got `say("text")`
- 29 `.snap.new` files exist in working tree with the 1-arg format

**Fix:** Either:
- (A) Restore `speaker_ref` argument in `make_say`/`make_say_localized` + accept snapshots with 2-arg format, OR
- (B) Update `say` builtin signature from `say(Entity, string)` to `say(string)` + accept 1-arg snapshots + fix emit test fixture

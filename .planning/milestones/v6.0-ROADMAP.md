### Phase 62: Clippy Warning Elimination
**Goal**: All 9 Rust crates compile with zero clippy warnings
**Depends on**: Nothing (first phase of milestone)
**Requirements**: WARN-01, WARN-02
**Success Criteria** (what must be TRUE):
  1. `cargo clippy --workspace` exits with zero warnings and zero errors
  2. All 155 auto-fixable warnings have been applied via `cargo clippy --fix`
  3. The remaining 39 warnings (non-auto-fixable) are manually resolved
  4. No new `#[allow(...)]` suppressions added unless justified with a comment
**Plans**: 2 plans
Plans:

- [ ] 62-02-PLAN.md — Manually resolve remaining ~29 clippy warnings across all crates

**Depends on**: Phase 62
**Requirements**: SPLIT-03, SPLIT-04, SPLIT-05, SPLIT-08, SPLIT-09, SPLIT-10, SPLIT-11
**Success Criteria** (what must be TRUE):
  1. No file in writ-compiler exceeds 500 lines (or each file has a documented rationale for remaining larger)
  2. Each new submodule has a single clear responsibility (e.g., check_expr/binary.rs handles binary expressions only)
  3. All existing tests pass without modification after the splits
  4. `mod` declarations in parent modules are explicit — no `pub use *` re-exports that obscure origin

### Phase 65: Code Duplication and Module Boundaries
**Goal**: Duplicate code patterns are consolidated and public API surfaces are tightened across all crates
**Depends on**: Phase 63, Phase 64
**Requirements**: DUP-01, DUP-02, MOD-01, MOD-02, MOD-03
**Success Criteria** (what must be TRUE):
  1. The `lower_dlg_text`/`lower_fmt_string` duplication is resolved — one shared helper or a clear explanation of why they must differ
  2. Wildcard imports (`use foo::*`) are replaced with explicit imports in all crates except deliberate prelude re-exports

### v6.1 LSP/DAP Fixes (In Progress)

**Milestone Goal:** Fix broken LSP completions, resolve DAP runtime decode error and multi-file launch gap, and add golden tests for dialogue/function mix patterns.

## Phase Details

### Phase 67: LSP Completions
**Goal**: Users get accurate auto-completion for method calls on typed expressions and for built-in namespaces
**Depends on**: Phase 66
**Requirements**: LSP-01, LSP-02
**Success Criteria** (what must be TRUE):
  1. Typing `.` after a typed variable in VS Code shows the correct methods for that type as completion items
  2. Typing `log::` shows `trace`, `debug`, `info`, `warn`, `error` as completion items
  3. Typing `Option::` shows `Some` and `None` as completion items
  4. Dot-completions use the receiver's resolved type from the type checker, not a fallback empty list
**Plans**: 2 plans

Plans:
- [ ] 67-01-PLAN.md — Add namespace completions for :: trigger (log::, Option::, Result::, user enums)
- [ ] 67-02-PLAN.md — Diagnose and fix dot-completion receiver lookup pipeline

### Phase 68: DAP Runtime and Launch Fixes
**Goal**: Users can run quest_system.writ through DAP without decode errors, and can launch multi-file writ.toml projects
**Depends on**: Phase 67
**Requirements**: DAP-01, DAP-02
**Success Criteria** (what must be TRUE):
  1. Launching quest_system.writ via DAP runs to completion without "Switch target byte offset not found in offset map" error
  2. A writ.toml project with multiple .writ files can be launched through DAP using the project root as the launch target
  3. DAP compile_and_load resolves all source files listed in writ.toml, not just the single entry-point file
**Plans**: 2 plans

Plans:
- [ ] 68-01-PLAN.md — Fix SWITCH byte-offset encoding in serialize.rs (DAP-01)
- [ ] 68-02-PLAN.md — Add multi-file writ.toml project launch to DAP (DAP-02)

### Phase 69: Dialogue/Function Golden Tests
**Goal**: Golden test suite covers dialogue/function mix patterns and the full quest pattern, with all snapshots blessed and passing
**Depends on**: Phase 68
**Requirements**: GOLD-01, GOLD-02
**Success Criteria** (what must be TRUE):
  1. A golden test file that mixes functions and dialogue blocks (calling each other) compiles without errors and has a blessed snapshot
  2. A golden test file implementing the full quest pattern (entity + dialogue + functions + choices) compiles without errors and has a blessed snapshot
  3. Both golden tests are registered in the test suite and pass under `cargo test --workspace`
**Plans**: 1 plan

Plans:
- [ ] 69-01-PLAN.md — Write dlg/fn mix and quest pattern golden tests, bless snapshots

Add namespace completion support for `::` trigger character in the LSP server.

Output: Working `::` completions for log namespace (5 levels), Option (Some/None), Result (Ok/Err), and user-defined enums. Unit tests proving each case.

1. In `completion.rs`, add a new public function `extract_namespace_prefix(source: &str, cursor: usize) -> Option<String>`:
   - Walk backward from `cursor` while bytes are `b':'`, decrement `i`. This skips trailing colons.
   - Record `end = i` (position after the identifier, before the colons).
   - Continue walking backward while `bytes[i-1].is_ascii_alphanumeric() || bytes[i-1] == b'_'`.
   - Record `start = i`.
   - If `start == end`, return `None` (no identifier found before colons).
   - Verify at least 2 colons were consumed (i.e., `cursor - end >= 2`). If only 1 colon, return `None` -- this is the first keypress in a `::` sequence.
   - Return `Some(std::str::from_utf8(&bytes[start..end]).ok()?.to_string())`.

2. In `completion.rs`, add a new public function:
   ```rust
   pub fn build_namespace_completions(
       namespace: &str,
       def_map: &DefMap,
       type_env: &writ_compiler::check::env::TypeEnv,
   ) -> Vec<CompletionItem>
   ```
   Implementation:
   a. **Hardcoded prelude types** -- check for exact namespace matches first:
      - If `namespace == "Option"`: return two items `CompletionItem { label: "Some", kind: Some(CompletionItemKind::ENUM_MEMBER), ..Default::default() }` and `CompletionItem { label: "None", kind: Some(CompletionItemKind::ENUM_MEMBER), ..Default::default() }`.
      - If `namespace == "Result"`: return two items `Ok` and `Err` with kind `ENUM_MEMBER`.
   b. **DefMap by_fqn prefix scan** -- build `prefix = format!("{}::", namespace)`, iterate `def_map.by_fqn`, for each `(fqn, &def_id)` where `fqn.starts_with(&prefix)`:
      - Extract `simple_name = fqn.strip_prefix(&prefix).unwrap_or(fqn)`.
      - Get `entry = def_map.get_entry(def_id)`.
      - Map `entry.kind` to CompletionItemKind: `DefKind::Fn | DefKind::ExternFn => FUNCTION`, `DefKind::Enum => ENUM`, `_ => VALUE`.
      - Push `CompletionItem { label: simple_name.to_string(), kind: Some(kind), ..Default::default() }`.
   c. **User-defined enum variants** -- if no items found from by_fqn scan, try enum variant lookup:
      - Find a DefId in `def_map.by_fqn` where `entry.name == namespace && entry.kind == DefKind::Enum`.
      - If found, look up `type_env.enum_variants.get(&def_id)`.
      - For each `EnumVariantSig { name, .. }` in variants, push `CompletionItem { label: name.clone(), kind: Some(CompletionItemKind::ENUM_MEMBER), ..Default::default() }`.
   d. Return `items`.

    // ... dot-completion path ...

Add a NEW branch BETWEEN the dot-completion `if` block and the identifier completion fallthrough:

```rust
if trigger_char == Some(":") {
    // NAMESPACE COMPLETION (LSP-02)
    // Trigger arrives once per ':' keypress. On the first ':', the source has
    // "foo:" — extract_namespace_prefix returns None (needs at least "::").
    // On the second ':', the source has "foo::" — extraction succeeds.
    let byte_offset = match crate::queries::position_to_byte_offset(&source, pos) {
        Some(o) => o,
        None => return Ok(None),
    };
    if let Some(namespace) = crate::queries::completion::extract_namespace_prefix(&source, byte_offset) {
        // Use cached analysis — no re-analysis needed for :: completions
        let cache_entry = match self.analysis_cache.get(&uri_str) {
            Some(e) => e.clone(),
            None => return Ok(None),
        };
        let (typed_ast, type_env) = match (&cache_entry.typed_ast, &cache_entry.type_env) {
            (Some(t), Some(e)) => (t, e),
            _ => return Ok(None),
        };
        let items = crate::queries::build_namespace_completions(
            &namespace,
            &typed_ast.def_map,
            type_env,
        );
        if items.is_empty() {
            return Ok(None);
        }
        return Ok(Some(CompletionResponse::Array(items)));
    }
    // First colon of "::" — no valid namespace yet, return nothing
    return Ok(None);
}
```

- Uses CACHED analysis (no `analyze_standalone` re-run) because `::` doesn't invalidate the source syntax.
- Returns `Ok(None)` for the first colon keypress (when `extract_namespace_prefix` returns `None`).

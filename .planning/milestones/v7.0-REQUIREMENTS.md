# Requirements: Writ Benchmark Suite

**Defined:** 2026-03-20
**Core Value:** Reproducible, fair cross-language performance comparison with one-command Docker execution

## v7.0 Requirements

### Benchmark Programs

- [x] **BENCH-01**: Fibonacci recursive benchmark runs in all 6 languages with equivalent algorithm
- [x] **BENCH-02**: Prime sieve (Eratosthenes) benchmark runs in all 6 languages with equivalent algorithm
- [x] **BENCH-03**: String concatenation benchmark runs in all 6 languages with equivalent algorithm
- [x] **BENCH-04**: Array sort benchmark runs in all 6 languages with equivalent algorithm
- [x] **BENCH-05**: Hash map insert/lookup benchmark runs in all 6 languages with equivalent algorithm
- [x] **BENCH-06**: OOP virtual dispatch benchmark runs in all 6 languages with equivalent algorithm
- [x] **BENCH-07**: Object creation benchmark runs in all 6 languages with equivalent algorithm
- [x] **BENCH-08**: Each benchmark produces a verifiable output to confirm correct execution

### Infrastructure

- [x] **INFRA-01**: Docker container includes all 6 language runtimes (Writ, Lua 5.4, Squirrel 3.x, Python 3.x, Node.js LTS, Rust)
- [x] **INFRA-02**: `run.sh` script runs all benchmarks using only Docker/Podman (no other prerequisites)
- [x] **INFRA-03**: `run.ps1` script runs all benchmarks using only Docker/Podman (no other prerequisites)
- [x] **INFRA-04**: Benchmark harness measures execution time (median ± MAD over N runs)
- [x] **INFRA-05**: Benchmark harness measures peak memory usage (anonymous RSS)
- [x] **INFRA-06**: Benchmark harness measures startup time per language
- [x] **INFRA-07**: Writ compile time and runtime reported as separate columns
- [x] **INFRA-08**: Results output as JSON for pipeline consumption

### Reporting

- [x] **REPORT-01**: SVG bar charts generated for each benchmark category (execution time)
- [x] **REPORT-02**: SVG bar chart for memory usage comparison
- [x] **REPORT-03**: SVG bar chart for startup time comparison
- [x] **REPORT-04**: Markdown table generated with all metrics for README embedding
- [x] **REPORT-05**: Charts and tables committed to `benchmark/results/`

### CI

- [x] **CI-01**: GitHub Actions workflow runs benchmarks on `workflow_dispatch` trigger
- [x] **CI-02**: GitHub Actions workflow runs benchmarks on weekly schedule
- [x] **CI-03**: CI results uploaded as artifacts

## Future Requirements

### v7.1+

- **BENCH-09**: Matrix multiply benchmark across all languages
- **BENCH-10**: Tree traversal benchmark across all languages
- **REPORT-06**: Historical trend charts showing performance over time
- **CI-04**: Regression detection with configurable threshold

## Out of Scope

| Feature | Reason |
|---------|--------|
| LuaJIT comparison | LuaJIT does not support Lua 5.3+ syntax; unfair comparison with PUC Lua 5.4 |
| GDScript / AngelScript | Not requested for v7.0; can be added later |
| Live dashboard | Maintenance burden; static SVG in README is simpler and always current |
| Energy/power measurement | Requires Intel RAPL; not portable across CI runners and Docker |
| JIT warmup runs | Game scripts run cold; warmup misrepresents actual use patterns |

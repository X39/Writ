Create `benchmark/runner/Dockerfile` with three stages. The Docker build context is the repo root (invoked as `docker build -t writ-bench -f benchmark/runner/Dockerfile .`).

**Stage 1: writ-builder** (builds the writ CLI binary)
```dockerfile
FROM rust:1.85-slim AS writ-builder
WORKDIR /writ
COPY Cargo.toml Cargo.lock ./
COPY writ-assembler/ writ-assembler/
COPY writ-cli/ writ-cli/
COPY writ-compiler/ writ-compiler/
COPY writ-dap/ writ-dap/
COPY writ-diagnostics/ writ-diagnostics/
COPY writ-golden/ writ-golden/
COPY writ-lsp/ writ-lsp/
COPY writ-module/ writ-module/
COPY writ-parser/ writ-parser/
COPY writ-runtime/ writ-runtime/
RUN cargo build --release --bin writ
```
Note: Copy individual crate directories rather than `COPY . .` to avoid sending the entire git history and benchmark directory as context. This improves Docker layer caching -- only crate source changes invalidate the build.

**Stage 2: rust-bench-builder** (compiles Rust benchmark stubs)
```dockerfile
FROM rust:1.85-slim AS rust-bench-builder
WORKDIR /bench
COPY benchmark/cases/ ./cases/
RUN mkdir -p /bench/bin && \
    for rs in cases/*/*.rs; do \
        name=$(basename "$(dirname "$rs")"); \
        rustc -O -o "/bench/bin/${name}" "$rs"; \
    done
```
Note: Iterates over `cases/*/\*.rs` so each benchmark suite directory's `.rs` file produces a binary named after the suite directory (e.g., `cases/stub/stub.rs` -> `bin/stub`).

**Stage 3: runtime** (the final image with all runtimes)
Base: `ubuntu:24.04`

Install in this order (each as a separate RUN layer for caching):

1. **System packages + Lua 5.4 + Python 3.12 + jq + Squirrel build deps:**
```dockerfile
RUN apt-get update && \
    DEBIAN_FRONTEND=noninteractive apt-get install -y --no-install-recommends \
    lua5.4 python3 jq \
    cmake build-essential git \
    curl ca-certificates gnupg && \
    rm -rf /var/lib/apt/lists/*
```

2. **Node.js 22 LTS via NodeSource (GPG key import method, NOT pipe-to-bash):**
```dockerfile
RUN mkdir -p /etc/apt/keyrings && \
    curl -fsSL https://deb.nodesource.com/gpgkey/nodesource-repo.gpg.key \
    | gpg --dearmor -o /etc/apt/keyrings/nodesource.gpg && \
    echo "deb [signed-by=/etc/apt/keyrings/nodesource.gpg] https://deb.nodesource.com/node_22.x nodistro main" \
    > /etc/apt/sources.list.d/nodesource.list && \
    apt-get update && \
    DEBIAN_FRONTEND=noninteractive apt-get install -y nodejs && \
    rm -rf /var/lib/apt/lists/*
```
Per user decision: Node.js 22 LTS (NOT 20).

3. **Squirrel 3.2 from source (NOT from apt -- squirrel3 is absent from Ubuntu 24.04 Noble repos):**
```dockerfile
RUN git clone --depth 1 --branch v3.2 \
        https://github.com/albertodemichelis/squirrel.git /tmp/squirrel && \
    cd /tmp/squirrel && mkdir build && cd build && \
    cmake .. -DCMAKE_BUILD_TYPE=Release && make -j$(nproc) && \
    cp sq/sq /usr/local/bin/sq && \
    cd / && rm -rf /tmp/squirrel
```
Binary name is `sq` (NOT `squirrel` -- ARCHITECTURE.md incorrectly states `squirrel`; cmake produces `sq`).

4. **hyperfine 1.20.0 from GitHub Releases .deb:**
```dockerfile
RUN curl -sSL "https://github.com/sharkdp/hyperfine/releases/download/v1.20.0/hyperfine_1.20.0_amd64.deb" \
    -o /tmp/hyperfine.deb && \
    dpkg -i /tmp/hyperfine.deb && \
    rm /tmp/hyperfine.deb
```
Note: hyperfine is NOT in Ubuntu apt repos. Must install from GitHub Releases.

5. **Clean up build deps no longer needed (optional, reduces image size):**
```dockerfile
RUN apt-get purge -y cmake build-essential git && \

    rm -rf /var/lib/apt/lists/*
```

**Section 2: Helper functions**

`measure_anon_rss()` -- Measures peak anonymous RSS in KB for a given command:
```bash
measure_anon_rss() {
    local peak_kb=0
    "$@" > /dev/null 2>&1 &
    local pid=$!
    while kill -0 "$pid" 2>/dev/null; do
        local rss
        rss=$(awk '/^RssAnon:/{print $2}' "/proc/$pid/status" 2>/dev/null || echo 0)
        if [ "$rss" -gt "$peak_kb" ] 2>/dev/null; then
            peak_kb=$rss
        fi
    done
    wait "$pid" || true
    echo "$peak_kb"
}
```
Note: Uses `/proc/<pid>/status` `RssAnon` field. RssAnon == VmRSS - RssFile - RssShmem on kernel >= 4.5; ubuntu:24.04 uses kernel 6.x. Redirects stdout/stderr of the benchmarked command to /dev/null so only the peak_kb value is echoed. For very short processes, may return 0 (documented behavior).

`add_mad()` -- jq filter that computes MAD from the times[] array and adds it to the result object. Takes a hyperfine JSON file as stdin, outputs the results[0] object with an added `mad` field:
```bash
add_mad() {
    jq '.results[0] + {
        mad: (
            .results[0].times as $times |
            ($times | length) as $n |
            (.results[0].median) as $med |
            ($times | map((. - $med) | if . < 0 then -. else . end) | sort) as $devs |
            $devs[($n / 2 | floor)]
        )
    }'
}
```
This computes MAD as: median(|Xi - median(X)|). The jq `fabs` function may not be available in all jq versions, so use the inline `if . < 0 then -. else . end` pattern instead.

`run_hyperfine()` -- Wrapper that runs hyperfine and pipes through add_mad:
```bash
run_hyperfine() {
    local outfile="$1"; shift
    hyperfine --runs "$RUNS" --warmup "$WARMUP" \
        --export-json "$outfile" \
        "$@" 2>/dev/null
    add_mad < "$outfile"
}
```

**Section 4: Startup time measurement (INFRA-06)**

After the per-suite execution measurements, measure startup time for each language using the same stub files. Startup time is the wall-clock time for a minimal hello-world program. Run hyperfine on each language's stub and extract the median as `startup_ms` (converted from seconds to milliseconds).

```bash
startup_json='{}'
for lang_cmd in \
    "writ:writ run /tmp/stub.writc" \
    "lua:lua5.4 /bench/cases/stub/stub.lua" \
    "squirrel:sq /bench/cases/stub/stub.nut" \
    "python:python3 /bench/cases/stub/stub.py" \
    "node:node /bench/cases/stub/stub.js" \
    "rust:/bench/bin/stub"; do
    lang_name="${lang_cmd%%:*}"
    lang_exec="${lang_cmd#*:}"
    hyperfine --runs "$RUNS" --warmup "$WARMUP" \
        --export-json /tmp/startup_${lang_name}.json \
        "$lang_exec" 2>/dev/null
    ms_val=$(jq '.results[0].median * 1000' /tmp/startup_${lang_name}.json)
    startup_json=$(echo "$startup_json" | jq --arg k "${lang_name}_ms" --argjson v "$ms_val" '. + {($k): $v}')
done
```

Note: Writ startup uses the pre-compiled `/tmp/stub.writc` (compile once before the loop). Ensure the stub is compiled at the start of the script, before the benchmark loop, with `writ compile /bench/cases/stub/stub.writ -o /tmp/stub.writc`.

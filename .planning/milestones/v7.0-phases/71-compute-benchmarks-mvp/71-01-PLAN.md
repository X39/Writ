**Algorithm (locked):** Naive recursive fib(40). Base cases: fib(0)=0, fib(1)=1, fib(n)=fib(n-1)+fib(n-2). Expected output: `102334155`.

**fib.writ:**
```writ
fn fib(n: int) -> int {
    if n <= 1 {
        n
    } else {
        fib(n - 1) + fib(n - 2)
    }
}

fn main() {
    let result: int = fib(40);
    log::info($"{result}");
}
```
Note: `log::info()` takes a `string` argument. Use format string `$"{result}"` to convert int to string. Output goes to stderr as `[INFO] 102334155`. The `fn main()` entry point is required (not `pub fn main()`).

**fib.lua:**
```lua
local function fib(n)
    if n <= 1 then return n end
    return fib(n - 1) + fib(n - 2)
end
print(fib(40))
```
Note: `local function` is idiomatic Lua. `print()` adds a newline.

**fib.nut (Squirrel):**
```squirrel
function fib(n) {
    if (n <= 1) return n;
    return fib(n - 1) + fib(n - 2);
}
print(fib(40) + "\n");
```
Note: Squirrel `print()` does NOT add a newline. Must concatenate `"\n"` explicitly. Squirrel auto-coerces integer to string in concatenation.

**fib.py:**
```python
import sys
sys.setrecursionlimit(10000)

def fib(n):
    if n <= 1:
        return n
    return fib(n - 1) + fib(n - 2)

print(fib(40))
```
Note: fib(40) naive recursive triggers ~2^40 calls. Python's default recursion limit (1000) is too low. Set `sys.setrecursionlimit(10000)` as safety measure. The recursion depth for fib(40) is 40, well within 10000.

**fib.js:**
```javascript
function fib(n) {
    if (n <= 1) return n;
    return fib(n - 1) + fib(n - 2);
}
console.log(fib(40));
```
Note: `console.log()` adds a newline. Node.js handles deep recursion fine for depth 40.

**fib.rs:**
```rust
fn fib(n: u64) -> u64 {
    if n <= 1 { return n; }
    fib(n - 1) + fib(n - 2)
}

fn main() {
    println!("{}", fib(40));
}
```
Note: Uses `u64` since fib(40)=102334155 fits. Single-file compilation with `rustc -O` (no Cargo, no external crates). `fn main()` is required.

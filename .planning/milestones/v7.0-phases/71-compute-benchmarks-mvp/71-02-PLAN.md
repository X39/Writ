**Algorithm (locked):** Eratosthenes sieve to N=1,000,000. Create boolean array of size N+1 (1,000,001 elements), mark composites, count remaining primes. Expected output: `78498`.

**sieve.writ:**
Uses `.push()` (from Task 1) to build the 1,000,001-element array, then marks composites with `sieve[j] = 0`, then counts remaining 1s.

```writ
fn main() {
    let n: int = 1000000;
    let mut sieve: int[] = [];
    let mut i: int = 0;
    while i <= n {
        sieve.push(1);
        i = i + 1;
    }
    sieve[0] = 0;
    sieve[1] = 0;
    i = 2;
    while i * i <= n {
        if sieve[i] == 1 {
            let mut j: int = i * i;
            while j <= n {
                sieve[j] = 0;
                j = j + i;
            }
        }
        i = i + 1;
    }
    let mut count: int = 0;
    let mut k: int = 0;
    while k <= n {
        count = count + sieve[k];
        k = k + 1;
    }
    log::info($"{count}");
}
```

Key Writ patterns: `let mut` for mutable bindings, `while` loops (no range-based for), `int[]` as boolean proxy (0/1), `log::info($"{count}")` for output (format string converts int to string), `.push()` for dynamic array growth.

**sieve.rs:**
```rust
fn main() {
    let n: usize = 1_000_000;
    let mut sieve = vec![true; n + 1];
    sieve[0] = false;
    sieve[1] = false;
    let mut i = 2;
    while i * i <= n {
        if sieve[i] {
            let mut j = i * i;
            while j <= n {
                sieve[j] = false;
                j += i;
            }
        }
        i += 1;
    }
    let count = sieve.iter().filter(|&&x| x).count();

}
```

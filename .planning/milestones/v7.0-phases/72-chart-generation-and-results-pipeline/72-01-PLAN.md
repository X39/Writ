Create `benchmark/generate.py` as a standalone Python 3.10+ script (~180-220 lines). The script takes one positional argument: the path to `raw.json`. All output files are written to the same directory as `raw.json`.

**CLI interface:**
- `python3 benchmark/generate.py <path-to-raw.json>`
- Exit 1 with usage message if argc != 2
- Exit 1 with error if raw.json does not exist or is not valid JSON

**Constants (top of file):**
- Language canonical order (used for ALL charts to keep color consistency):
  `ALL_LANGS = [('Writ', 'writ'), ('Rust', 'rust'), ('Lua', 'lua'), ('Squirrel', 'squirrel'), ('Python', 'python'), ('Node.js', 'node')]`
- Interpreted-only subset: `INTERP_LANGS = [l for l in ALL_LANGS if l[0] != 'Rust']`
- Color palette tuple (must match ALL_LANGS order): `('#7c3aed', '#ea580c', '#2563eb', '#0d9488', '#eab308', '#16a34a')`
- `CHART_STYLE = Style(background='white', plot_background='white', foreground='#333333', foreground_strong='#000000', foreground_subtle='#999999', colors=LANG_COLORS)`
- `_DATE_COMMENT_RE = re.compile(r'&lt;!--Generated with pygal[^>]*-->')`

**Helper functions:**
- `make_chart(title, y_title, logarithmic=False)` — returns `pygal.Bar(style=CHART_STYLE, disable_xml_declaration=True, no_prefix=True, title=title, y_title=y_title, logarithmic=logarithmic, height=400, width=900, show_legend=True, print_values=False)`
- `render_svg(chart, path)` — calls `chart.render()`, strips date comment via `_DATE_COMMENT_RE.sub('&lt;!--Generated with pygal-->', svg_text)`, writes to `path` with `encoding='utf-8'`. CRITICAL: `chart.render()` returns bytes in pygal 3.1.0 — must `.decode('utf-8')` before regex sub, then write as text.
- `writ_total_ms(b)` — `(b['writ_compile']['median'] + b['writ_run']['median']) * 1000`
- `writ_compile_ms(b)` — `b['writ_compile']['median'] * 1000`
- `writ_run_ms(b)` — `b['writ_run']['median'] * 1000`
- `lang_ms(b, key)` — `b[key]['median'] * 1000` if key exists in b, else None
- `lang_memory_mb(b, key)` — `b[key].get('memory_kb', 0) / 1024.0` if key exists, else 0.0
- `ratio_str(ms, rust_ms)` — returns `f'x{ms / rust_ms:.1f}x'` or `'N/A'` if rust_ms is 0

**Chart generation functions:**

1. `generate_exec_charts(b, out_dir)` — For each benchmark entry `b`:
   - All-languages log-scale chart: title `f'Execution Time -- {suite} (log scale, all languages)'`, y_title `'Time (ms)'`, `logarithmic=True`. One series per language via `chart.add(name, [value])`. For Writ, value is `{'value': round(wc + wr, 3), 'label': f'compile: {wc:.2f}ms, run: {wr:.2f}ms'}`. For other languages, value is `round(ms, 3)`. Set `chart.x_labels = [name for name, _ in ALL_LANGS]`. Output: `exec_{suite}_all.svg`
   - Interpreted-only linear-scale chart: same pattern but uses `INTERP_LANGS`, `logarithmic=False`, title says `'(interpreted languages)'`. Output: `exec_{suite}_interp.svg`

2. `generate_memory_chart(benchmarks, out_dir)` — One grouped bar chart across all suites. Title `'Memory Usage by Benchmark'`, y_title `'Memory (MB)'`, linear scale. `chart.x_labels = [b['suite'] for b in benchmarks]`. One series per language (in ALL_LANGS order): for each benchmark, Writ uses `lang_memory_mb(b, 'writ_run')` (runtime, not compiler). For memory_kb=0 entries, use `{'value': 0, 'label': 'not measured (process too fast)'}`. Output: `memory.svg`

3. `generate_startup_chart(benchmarks, out_dir)` — Uses `benchmarks[0]['startup']` sub-object (startup is measured once, same for all suites). Title `'Startup Time by Language'`, y_title `'Time (ms)'`, linear scale. Keys: `('Writ','writ_ms'), ('Rust','rust_ms'), ('Lua','lua_ms'), ('Squirrel','squirrel_ms'), ('Python','python_ms'), ('Node.js','node_ms')`. Each language gets `chart.add(name, [round(startup.get(key, 0), 3)])`. Set `chart.x_labels` to language names. Output: `startup.svg`

4. `generate_results_md(data, out_dir)` — Produces `RESULTS.md` with:
   - Header: `# Benchmark Results -- {meta['date']}`
   - Subheader: `Platform: {meta['platform']} | Runs: {meta['runs']} | Warmup: {meta['warmup']}`
   - Note: `*Memory values of 0.0 MB indicate the process exited before RSS polling could sample it.*`
   - Per-suite section with `## {suite}` header
   - Table columns: `| Language | Benchmark | Median (ms) | Compile (ms) | Memory (MB) | Ratio to Rust |`
   - Separator: `|----------|-----------|-------------|--------------|-------------|---------------|`
   - Writ row: shows compile_ms in Compile column, combined time in Median column
   - Other languages: dash `-` in Compile column
   - Precision: 1 decimal place for all numeric values
   - Ratio format: `x{N.N}x` via `ratio_str()`
   - Rust ratio is always `x1.0x`
   - Write with `\n`.join(lines) + trailing newline, encoding='utf-8'

**main() function:**
- Parse sys.argv[1] as Path, resolve to absolute
- Load JSON
- `out_dir = raw_path.parent`
- For each benchmark in data['benchmarks']: call `generate_exec_charts(b, out_dir)`
- Call `generate_memory_chart(data['benchmarks'], out_dir)`
- Call `generate_startup_chart(data['benchmarks'], out_dir)`
- Call `generate_results_md(data, out_dir)`
- Print summary: `f'Generated {N} SVG charts + RESULTS.md in {out_dir}'`

**Determinism requirements (per user decision):**
- `disable_xml_declaration=True` on all charts
- `no_prefix=True` on all charts (eliminates UUID CSS selectors)
- Strip date comment via regex after render
- No timestamps, random IDs, or non-deterministic content anywhere
- Always add series in ALL_LANGS order for color consistency

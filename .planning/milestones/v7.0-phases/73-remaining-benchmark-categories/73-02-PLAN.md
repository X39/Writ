Create directory `benchmark/cases/array_sort/` and 6 source files. Algorithm (locked): create an array of 100,000 integers in descending order (100000, 99999, ..., 1). Sort ascending using Lomuto partition quicksort (same algorithm in all languages -- NOT built-in sort). Print first and last elements separated by a space. Expected output: `1 100000`.

**Lomuto Partition Quicksort (canonical, use in all 6 languages):**
```
partition(arr, lo, hi):
    pivot = arr[hi]
    i = lo - 1
    for j = lo to hi-1:
        if arr[j] <= pivot:
            i = i + 1
            swap arr[i], arr[j]
    swap arr[i+1], arr[hi]
    return i + 1

quicksort(arr, lo, hi):
    if lo < hi:
        p = partition(arr, lo, hi)
        quicksort(arr, lo, p - 1)
        quicksort(arr, p + 1, hi)
```

**array_sort.writ:**
```writ
fn partition(arr: int[], lo: int, hi: int) -> int {
    let pivot: int = arr[hi];
    let mut i: int = lo - 1;
    let mut j: int = lo;
    while j < hi {
        if arr[j] <= pivot {
            i = i + 1;
            let tmp: int = arr[i];
            arr[i] = arr[j];
            arr[j] = tmp;
        }
        j = j + 1;
    }
    let tmp: int = arr[i + 1];
    arr[i + 1] = arr[hi];
    arr[hi] = tmp;
    i + 1
}

fn quicksort(arr: int[], lo: int, hi: int) {
    if lo < hi {
        let p: int = partition(arr, lo, hi);
        quicksort(arr, lo, p - 1);
        quicksort(arr, p + 1, hi);
    }
}

fn main() {
    let mut arr: int[] = [];
    let mut i: int = 100000;
    while i >= 1 {
        arr.push(i);
        i = i - 1;
    }
    quicksort(arr, 0, 99999);
    log::info($"{arr[0]} {arr[99999]}");
}
```
Note: Writ arrays are mutable by reference when passed to functions. The `while j < hi` loop replaces a for-loop since Writ has no C-style for. The recursion limit for quicksort on 100k elements with Lomuto on sorted input is O(n) stack depth -- this is a known worst-case for Lomuto on reverse-sorted input. To avoid stack overflow, use a random pivot or median-of-three. Recommended: use median-of-three pivot selection instead of `arr[hi]` in the partition function:
```
let mid: int = lo + (hi - lo) / 2;
// sort lo, mid, hi and use mid as pivot
if arr[lo] > arr[mid] { swap(arr, lo, mid); }
if arr[lo] > arr[hi] { swap(arr, lo, hi); }
if arr[mid] > arr[hi] { swap(arr, mid, hi); }
// now arr[mid] is median -- swap to hi position for standard Lomuto
swap(arr, mid, hi);
let pivot: int = arr[hi];
```
Apply the same median-of-three pivot selection in ALL 6 languages to avoid O(n) recursion depth on the descending-order input.

**array_sort.rs:**
```rust
fn partition(arr: &mut [i64], lo: usize, hi: usize) -> usize {
    let mid = lo + (hi - lo) / 2;
    if arr[lo] > arr[mid] { arr.swap(lo, mid); }
    if arr[lo] > arr[hi] { arr.swap(lo, hi); }
    if arr[mid] > arr[hi] { arr.swap(mid, hi); }
    arr.swap(mid, hi);
    let pivot = arr[hi];
    let mut i = lo;
    for j in lo..hi {
        if arr[j] <= pivot {
            arr.swap(i, j);
            i += 1;
        }
    }
    arr.swap(i, hi);
    i
}

fn quicksort(arr: &mut [i64], lo: usize, hi: usize) {
    if lo < hi {
        let p = partition(arr, lo, hi);
        if p > 0 { quicksort(arr, lo, p - 1); }
        quicksort(arr, p + 1, hi);
    }
}

fn main() {
    let n: usize = 100_000;
    let mut arr: Vec<i64> = (0..n).map(|i| (n - i) as i64).collect();
    quicksort(&mut arr, 0, n - 1);
    println!("{} {}", arr[0], arr[n - 1]);
}
```
Note: Rust uses `usize` for indices and `i64` for values. The `i` variable in partition starts at `lo` (not `lo - 1`) because `usize` cannot go negative; the Lomuto pattern is adjusted accordingly (increment happens AFTER swap, not before).

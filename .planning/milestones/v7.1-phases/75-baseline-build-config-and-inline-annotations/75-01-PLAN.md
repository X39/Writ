**Step 1 — helpers.rs (INLINE-01):**

Add `#[inline(always)]` immediately before each of these 5 functions:
- `pub(super) fn extract_int(val: &Value) -> i64`
- `pub(super) fn extract_float(val: &Value) -> f64`
- `pub(super) fn extract_bool(val: &Value) -> bool`
- `pub(super) fn extract_ref(val: &Value) -> HeapRef`
- `pub(super) fn extract_entity(val: &Value) -> EntityId`

Do NOT annotate `get_type_field_count` (not a hot-path extraction function).

**Step 2 — arith.rs (INLINE-02):**

Add `#[inline]` (NOT `#[inline(always)]`) immediately before EVERY `pub(super) fn exec_*` function in arith.rs. There are approximately 45 functions including:
- exec_crash, exec_mov, exec_load_int, exec_load_float, exec_load_true, exec_load_false, exec_load_string, exec_load_null
- exec_br, exec_br_true, exec_br_false, exec_switch
- exec_add_i, exec_sub_i, exec_mul_i, exec_div_i, exec_mod_i, exec_neg_i
- exec_add_f, exec_sub_f, exec_mul_f, exec_div_f, exec_mod_f, exec_neg_f
- exec_bit_and, exec_bit_or, exec_shl, exec_shr, exec_not
- exec_cmp_eq_i, exec_cmp_eq_f, exec_cmp_eq_b, exec_cmp_eq_s, exec_cmp_lt_i, exec_cmp_lt_f
- exec_i2f, exec_f2i, exec_i2s, exec_f2s, exec_b2s, exec_convert
- exec_str_concat, exec_str_build, exec_str_len, exec_s2i, exec_s2f, exec_s2b
- exec_box, exec_unbox

Every `pub(super) fn exec_*` in the file gets `#[inline]`.

**Step 3 — calls.rs (INLINE-03):**

Add `#[inline]` immediately before each of these call-dispatch functions:
- `pub(super) fn exec_call(`
- `pub(super) fn exec_call_virt(`
- `pub(super) fn exec_call_extern(`
- `pub(super) fn exec_call_indirect(`
- `pub(super) fn exec_tail_call(`

**Step 4 — mod.rs execute_ret (INLINE-03):**

Add `#[inline]` immediately before `fn execute_ret(` (located around line 505 in dispatch/mod.rs). This is called on every RET and TailCall instruction.

**Step 5 — Verify execute_one has NO inline (INLINE-04):**

Confirm that `pub(crate) fn execute_one(` (around line 210 in dispatch/mod.rs) does NOT have any `#[inline]` annotation. Do not add one. If one exists for any reason, remove it.

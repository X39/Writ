<objective>
Refactor all four call instruction handlers (exec_call, exec_call_virt, exec_call_indirect, exec_tail_call) to eliminate intermediate Vec allocations, then measure and record the performance improvement.

Purpose: Every call instruction currently allocates a staging Vec to collect arguments before writing them to the callee frame. For fib(40) which makes ~300M recursive calls, this is ~300M unnecessary heap allocations. Eliminating them is the core optimization of Phase 76.

Output: Modified calls.rs with zero-allocation patterns, updated BASELINE.md with Phase 76 timing delta.

**Part A: Refactor exec_tail_call (lines 270-306)**

Tail-call is structurally different from the other three: it replaces the current frame in-place rather than pushing a new one. The args are read from `current.registers[r_base..r_base+argc]`, then the same frame's registers are overwritten. This creates a self-aliasing problem.

Replace the Vec staging pattern with a fixed-size stack-resident buffer:

1. Define a const at the top of calls.rs (or inside exec_tail_call):
   ```rust
   const MAX_INLINE_ARGC: usize = 32;
   ```

2. Before the defer execution block (which may mutate the call stack), read arguments into the stack buffer:
   ```rust
   let argc_usize = argc as usize;
   let arg_buf: [Value; MAX_INLINE_ARGC] = std::array::from_fn(|_| Value::Void);
   ```
   Wait -- we need to read args BEFORE defers execute (defers may modify registers). The current code reads args at line 272 before defers at line 281. Preserve this ordering.

   Actually, looking at the current code more carefully: the args are collected at lines 272-278, THEN defers run at 281-292, THEN frame is replaced at 294-303. This means args must be saved before defers run, which is what the Vec does today. The stack buffer must also be filled before defers.

   Replace lines 271-278 with:
   ```rust
   let argc_usize = argc as usize;
   let mut arg_buf: [Value; MAX_INLINE_ARGC] = std::array::from_fn(|_| Value::Void);
   let mut heap_args: Vec<Value>;
   let use_heap = argc_usize > MAX_INLINE_ARGC;
   if use_heap {
       heap_args = Vec::with_capacity(argc_usize);
       let frame = ctx.task.call_stack.last().unwrap();
       for i in 0..argc_usize {
           heap_args.push(frame.registers[r_base as usize + i].clone());
       }
   } else {
       heap_args = Vec::new();
       let frame = ctx.task.call_stack.last().unwrap();
       for i in 0..argc_usize {
           arg_buf[i] = frame.registers[r_base as usize + i].clone();
       }
   }
   ```

   NOTE: `heap_args` must be declared with `let mut heap_args = Vec::new();` in the else branch to satisfy the borrow checker. Alternatively, restructure so the variable exists before the if/else. The simplest correct form:

   ```rust
   let argc_usize = argc as usize;
   const MAX_INLINE_ARGC: usize = 32;
   let mut arg_buf: [Value; MAX_INLINE_ARGC] = std::array::from_fn(|_| Value::Void);
   let mut heap_args: Option<Vec<Value>> = None;
   {
       let frame = ctx.task.call_stack.last().unwrap();
       if argc_usize > MAX_INLINE_ARGC {
           let mut hv = Vec::with_capacity(argc_usize);
           for i in 0..argc_usize {
               hv.push(frame.registers[r_base as usize + i].clone());
           }
           heap_args = Some(hv);
       } else {
           for i in 0..argc_usize {
               arg_buf[i] = frame.registers[r_base as usize + i].clone();
           }
       }
   }
   ```

3. Keep the defer execution block (lines 281-292) unchanged.

4. Replace the frame replacement (lines 294-303) with:
   ```rust
   let current = ctx.task.call_stack.last_mut().unwrap();
   current.method_idx = method_idx;
   current.pc = 0;
   current.registers.clear();
   current.registers.resize(reg_count, Value::Void);
   if let Some(hv) = heap_args {
       for (i, v) in hv.into_iter().enumerate() {
           if i < current.registers.len() {
               current.registers[i] = v;
           }
       }
   } else {
       for i in 0..argc_usize {
           current.registers[i] = std::mem::replace(&mut arg_buf[i], Value::Void);
       }
   }
   ```

   Using `clear()` + `resize()` instead of `vec![Value::Void; reg_count]` reuses the existing Vec allocation when possible (the Vec's capacity from the previous frame is preserved).

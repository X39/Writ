<objective>
Introduce an execute_batch inner dispatch loop that runs multiple instructions per task slice without returning to the scheduler, eliminating the per-instruction FxHashMap task lookup in run_one_task. Fall back to single-instruction dispatch when debug hooks are enabled.

Purpose: For fib(40) with ~300M instructions, the current run_one_task does ~300M `self.tasks.get_mut(&task_id)` HashMap lookups. execute_batch holds `&mut Task` across the entire batch, removing this overhead.
Output: execute_batch function in dispatch/mod.rs; restructured run_one_task in scheduler.rs; batch dispatch tests; fib(40) performance delta recorded.
</objective>

**Step 1: Add `execute_batch` to `writ-runtime/src/dispatch/mod.rs`.**

Add the following function AFTER `execute_one` (before the `// ── Helper functions` section). The function has the same parameter signature as `execute_one` plus a `limit: u64` parameter (0 = unlimited):

```rust
/// Execute instructions in a batch without returning to the scheduler between them.
///
/// Holds `&mut Task` across the entire batch, eliminating the per-instruction
/// HashMap task lookup that `run_one_task` would otherwise perform. Terminates
/// the batch on any non-Continue result or when the instruction budget is exhausted.
///
/// When `host.debug_enabled()` is true, falls back to single-instruction dispatch
/// to preserve the per-instruction `before_instruction` hook behavior.
#[allow(clippy::too_many_arguments)]
pub(crate) fn execute_batch(
    task: &mut Task,
    modules: &[LoadedModule],
    current_module_idx: usize,
    dispatch_table: &DispatchTable,
    heap: &mut dyn GcHeap,
    host: &mut dyn RuntimeHost,
    globals: &mut Vec<Value>,
    next_request_id: &mut u32,
    entity_registry: &mut EntityRegistry,
    pool: &mut RegisterPool,
    limit: u64,
) -> ExecutionResult {
    // DISPATCH-04: debug path — single instruction to preserve per-instruction hooks
    if host.debug_enabled() {
        return execute_one(task, modules, current_module_idx, dispatch_table,
                          heap, host, globals, next_request_id, entity_registry, pool);
    }

    let mut executed: u64 = 0;

    loop {
        // DISPATCH-03: respect limit with atomic-section awareness (never yield mid-atomic)
        if limit > 0 && executed >= limit && task.atomic_depth == 0 {
            return ExecutionResult::LimitReached;
        }

        // DISPATCH-01/DISPATCH-05: execute_one fetches task.call_stack.last_mut() fresh
        // on every call, so frame reference is always current after Call/Ret/TailCall
        let result = execute_one(task, modules, current_module_idx, dispatch_table,
                                heap, host, globals, next_request_id, entity_registry, pool);
        executed += 1;

        // DISPATCH-02: continue only on Continue; terminate on everything else
        match result {
            ExecutionResult::Continue => continue,
            other => return other,
        }
    }
}
```

**Step 2: Restructure `run_one_task` in `writ-runtime/src/scheduler.rs`.**

Replace the current `run_one_task` inner loop. The current pattern is:
- A `loop` that on every iteration does `self.tasks.get_mut(&task_id)` then calls `execute_one`, then matches on the result.

The new pattern:
1. Extract `task` reference once via `self.tasks.get_mut(&task_id)`
2. Call `execute_batch(task, ..., per_task_limit)` — this holds the borrow for the entire batch
3. After `execute_batch` returns (borrow released), match on the single result

Key restructuring details for `run_one_task`:

```rust
pub(crate) fn run_one_task(
    &mut self,
    modules: &[LoadedModule],
    current_module_idx: usize,
    dispatch_table: &DispatchTable,
    heap: &mut dyn GcHeap,
    host: &mut dyn RuntimeHost,
    limit: u64,
    next_request_id: &mut u32,
) -> Option<(TaskId, ExecutionResult)> {
    let task_id = self.ready_queue.pop_front()?;

    {
        let task = self.tasks.get_mut(&task_id)?;
        task.state = TaskState::Running;
    }

    loop {
        let result = {
            let task = self.tasks.get_mut(&task_id).unwrap();
            execute_batch(
                task,
                modules,
                current_module_idx,
                dispatch_table,
                heap,
                host,
                &mut self.globals,
                next_request_id,
                &mut self.entity_registry,
                &mut self.pool,
                limit,
            )
        };

        match result {
            ExecutionResult::Continue => continue,
            ExecutionResult::Completed(val) => {
                let task = self.tasks.get_mut(&task_id).unwrap();
                task.state = TaskState::Completed;
                task.return_value = Some(val.clone());
                self.wake_joiners(task_id, Some(val.clone()));
                return Some((task_id, ExecutionResult::Completed(val)));
            }
            ExecutionResult::Suspended(req_id) => {
                let task = self.tasks.get_mut(&task_id).unwrap();
                task.state = TaskState::Suspended;
                task.suspend_reason = Some(SuspendReason::HostRequest(req_id));
                return Some((task_id, ExecutionResult::Suspended(req_id)));
            }
            ExecutionResult::DebugSuspend => {
                return Some((task_id, ExecutionResult::DebugSuspend));
            }
            ExecutionResult::Crash(msg) => {
                if host.debug_enabled() {
                    let task = self.tasks.get_mut(&task_id).unwrap();
                    task.state = TaskState::Suspended;
                    task.suspend_reason = Some(SuspendReason::CrashPending {
                        message: msg.clone(),
                    });
                    return Some((task_id, ExecutionResult::DebugSuspend));
                }
                {
                    let task = self.tasks.get_mut(&task_id).unwrap();
                    execute_crash(
                        task, msg.clone(), modules, current_module_idx, dispatch_table, heap, host,
                        &mut self.globals, next_request_id,
                        &mut self.entity_registry, &mut self.pool,
                    );
                }
                let children = self.tasks.get(&task_id)
                    .map(|t| t.scoped_children.clone())
                    .unwrap_or_default();
                for child_id in children {
                    self.cancel_task_tree(child_id, modules, current_module_idx, dispatch_table, heap, host, next_request_id);
                }
                let locks: Vec<u32> = self.tasks.get(&task_id)
                    .map(|t| t.atomic_locks.clone())
                    .unwrap_or_default();
                for global_idx in locks {
                    self.global_locks.remove(&global_idx);
                }
                if let Some(t) = self.tasks.get_mut(&task_id) {
                    t.atomic_locks.clear();
                }
                self.wake_joiners(task_id, None);
                return Some((task_id, ExecutionResult::Crash(msg)));
            }
            ExecutionResult::LimitReached => {
                let task = self.tasks.get_mut(&task_id).unwrap();
                task.state = TaskState::Ready;
                self.ready_queue.push_back(task_id);
                return Some((task_id, ExecutionResult::LimitReached));
            }
            ExecutionResult::DeferComplete => {
                continue;
            }
            ExecutionResult::SpawnChild { r_dst, method_idx, args } => {
                let child_id = self.create_task(
                    method_idx, args, Some(task_id), &modules[current_module_idx],
                );
                if let Some(parent) = self.tasks.get_mut(&task_id) {
                    parent.scoped_children.push(child_id);
                    if let Some(frame) = parent.call_stack.last_mut() {
                        frame.registers[r_dst as usize] = pack_task_id(child_id);
                    }
                }
                continue;
            }
            ExecutionResult::SpawnDetachedTask { r_dst, method_idx, args } => {
                let child_id = self.create_task(
                    method_idx, args, None, &modules[current_module_idx],
                );
                if let Some(parent) = self.tasks.get_mut(&task_id)
                    && let Some(frame) = parent.call_stack.last_mut() {
                        frame.registers[r_dst as usize] = pack_task_id(child_id);
                    }
                continue;
            }
            ExecutionResult::JoinTask { r_dst, target } => {
                let target_info = self.tasks.get(&target)
                    .map(|t| (t.state, t.return_value.clone()));
                match target_info {
                    Some((TaskState::Completed, ret_val)) | Some((TaskState::Cancelled, ret_val)) => {
                        let task = self.tasks.get_mut(&task_id).unwrap();
                        if let Some(frame) = task.call_stack.last_mut() {
                            frame.registers[r_dst as usize] = ret_val.unwrap_or(Value::Void);
                        }
                        continue;
                    }
                    Some(_) => {
                        let task = self.tasks.get_mut(&task_id).unwrap();
                        task.state = TaskState::Suspended;
                        self.join_waiters
                            .entry(target)
                            .or_default()
                            .push((task_id, r_dst));
                        return Some((task_id, ExecutionResult::Suspended(
                            crate::host::RequestId(0),
                        )));
                    }
                    None => {
                        let task = self.tasks.get_mut(&task_id).unwrap();
                        if let Some(frame) = task.call_stack.last_mut() {
                            frame.registers[r_dst as usize] = Value::Void;
                        }
                        continue;
                    }
                }
            }
            ExecutionResult::CancelTask { target } => {
                self.cancel_task_tree(target, modules, current_module_idx, dispatch_table, heap, host, next_request_id);
                continue;
            }
        }
    }
}
```

Key changes from the current code:
- The `instructions_run` local counter and the per-iteration limit check at the top of the loop are REMOVED from `run_one_task`. Limit accounting is now inside `execute_batch`.
- `execute_one` is replaced by `execute_batch` in the inner call.
- The outer `loop` in `run_one_task` still exists for concurrency results (SpawnChild, JoinTask, etc.) that need scheduler state. `execute_batch` returns these immediately, and `run_one_task` handles them then re-enters the loop.
- For concurrency results that `continue`, `execute_batch` is called again on the next iteration. The `limit` is passed unchanged (simplicity; concurrency ops are rare).

fn batch_dispatch_fib_correctness() {
    // fib(10) = 55 — exercises batch dispatch through recursive calls.
    // This confirms execute_batch handles Continue, Call (stack push),
    // Ret (stack pop), and Completed correctly across many instructions.
    //
    // Method 0 (main): loads 10 into r0, calls method 1 (fib), returns result
    // Method 1 (fib):  if r0 <= 1 return r0; else return fib(r0-1) + fib(r0-2)
    //
    // Use the existing build_two_method_runtime helper from vm_tests.rs.
    // If no fib helper exists, construct the two-method module manually
    // following the same pattern as tail_call_passes_multiple_args.
    //
    // Expected: Value::Int(55)
    let main_instrs = vec![
        Instruction::LoadInt { r_dst: 0, value: 10 },
        Instruction::Call { r_base: 0, r_dst: 1, method_idx: 1, argc: 1 },
        Instruction::Ret { r_src: 1 },
    ];

    // fib(n): if n <= 1 return n; return fib(n-1) + fib(n-2)
    // r0 = n (argument), r1 = scratch, r2 = fib(n-1), r3 = fib(n-2), r4 = result
    let fib_instrs = vec![
        Instruction::LoadInt { r_dst: 1, value: 1 },
        Instruction::CmpLeI { r_dst: 2, r_a: 0, r_b: 1 },  // r2 = n <= 1
        Instruction::BrTrue { r_cond: 2, offset: 7 },       // if true, jump to ret
        // fib(n-1)
        Instruction::SubI { r_dst: 1, r_a: 0, r_b: 1 },    // r1 = n - 1 (reloads 1 below)
        Instruction::Call { r_base: 1, r_dst: 2, method_idx: 1, argc: 1 }, // r2 = fib(n-1)
        // fib(n-2)
        Instruction::LoadInt { r_dst: 1, value: 2 },
        Instruction::SubI { r_dst: 1, r_a: 0, r_b: 1 },    // r1 = n - 2
        Instruction::Call { r_base: 1, r_dst: 3, method_idx: 1, argc: 1 }, // r3 = fib(n-2)
        // return fib(n-1) + fib(n-2)
        Instruction::AddI { r_dst: 4, r_a: 2, r_b: 3 },
        Instruction::Ret { r_src: 4 },
        // base case: return n
        Instruction::Ret { r_src: 0 },
    ];

    let mut rt = build_two_method_runtime(&main_instrs, 2, &fib_instrs, 5);
    let task_id = rt.spawn_task(0, vec![]).unwrap();
    loop {
        match rt.tick(0.0, ExecutionLimit::None) {
            TickResult::AllCompleted => break,
            _ => continue,
        }
    }
    let ret = rt.task_return_value(task_id).unwrap();
    assert_eq!(ret, Value::Int(55), "fib(10) should be 55");
}

**Test 2: `batch_respects_execution_limit`** (covers DISPATCH-03)
Create a simple program that runs many instructions (e.g., a loop that increments a counter). Run it with `ExecutionLimit::Instructions(10)`. Verify the task is still Ready (not Completed) after one tick, proving the limit was respected. Then run with `ExecutionLimit::None` and verify completion.

```rust
#[test]
fn batch_respects_execution_limit() {
    // Program: r0 = 0; loop { r0 = r0 + 1; if r0 >= 100 { break; } }; ret r0
    // With limit=10, should not complete in one tick.
    let instrs = vec![
        Instruction::LoadInt { r_dst: 0, value: 0 },      // r0 = 0
        Instruction::LoadInt { r_dst: 1, value: 1 },      // r1 = 1
        Instruction::LoadInt { r_dst: 2, value: 100 },    // r2 = 100
        // loop start (pc=3):
        Instruction::AddI { r_dst: 0, r_a: 0, r_b: 1 },  // r0 += 1
        Instruction::CmpLtI { r_dst: 3, r_a: 0, r_b: 2 },// r3 = r0 < 100
        Instruction::BrTrue { r_cond: 3, offset: -2 },    // if r3 goto pc=3
        Instruction::Ret { r_src: 0 },                    // return r0
    ];
    let mut runtime = build_runtime(&instrs, 4);
    let task_id = runtime.spawn_task(0, vec![]).unwrap();

    // With a limit of 10 instructions, the loop (which needs ~300 instructions)
    // should NOT complete in one tick.
    let result = runtime.tick(0.0, ExecutionLimit::Instructions(10));
    assert!(
        matches!(result, TickResult::ExecutionLimitReached),
        "Expected ExecutionLimitReached with limit=10, got {:?}", result
    );

    // Task should be Ready (re-queued), not Completed
    let state = runtime.task_state(task_id).unwrap();
    assert_eq!(state, TaskState::Ready);

    // Now run unlimited — should complete with r0 = 100
    let result2 = runtime.tick(0.0, ExecutionLimit::None);
    assert!(matches!(result2, TickResult::AllCompleted));
    let ret = runtime.task_return_value(task_id).unwrap();
    assert_eq!(ret, Value::Int(100));
}
```

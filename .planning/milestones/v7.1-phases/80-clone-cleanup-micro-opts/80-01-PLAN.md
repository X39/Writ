Apply unsafe get_unchecked / get_unchecked_mut in the three argument-copy loops inside exec_call, exec_call_virt, and exec_call_indirect. These are the loops that copy arguments from caller registers to callee registers using the `split_at_mut` pattern.

**exec_call (around lines 31-35):** Replace:
```rust
for i in 0..argc as usize {
    if i < callee.registers.len() {
        callee.registers[i] = caller.registers[r_base as usize + i];
    }
}
```
With:
```rust
// SAFETY: The compiler guarantees argc <= callee reg_count and r_base + argc <= caller
// reg_count for every CALL instruction it emits. Both frames were sized from these
// values at creation time, so all indices are in-bounds.
for i in 0..argc as usize {
    unsafe {
        *callee.registers.get_unchecked_mut(i) =
            *caller.registers.get_unchecked(r_base as usize + i);
    }
}
```

**exec_call_virt (around lines 93-97):** Same transformation as exec_call — identical pattern. Same SAFETY comment.

**exec_call_indirect (around lines 229-233):** Same transformation as exec_call — identical pattern. Same SAFETY comment.

**Do NOT apply unsafe indexing to:**
- exec_tail_call (uses stack buffer, different pattern)
- exec_call_extern (builds Vec for host, not hot path)
- Any other register access site

After the unsafe changes, run the full test suite to confirm no panics or incorrect behavior. Then measure fib(40) in release mode:

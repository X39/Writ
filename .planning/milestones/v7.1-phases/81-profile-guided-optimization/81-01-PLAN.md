  <action>
Execute the complete PGO pipeline from the repo root (D:/dev/git/Writ):

1. Add `pgo-data/` to `.gitignore` (append to end of file) so profraw/profdata files are never staged.

2. Clean any prior profiling data and create the output directory:
   ```bash
   PGODIR="$(pwd)/pgo-data"
   rm -rf "$PGODIR"
   mkdir -p "$PGODIR"
   ```

3. Instrumented build (apply PGO instrumentation to entire workspace):
   ```bash
   RUSTFLAGS="-Cprofile-generate=$PGODIR" cargo build --release --target x86_64-pc-windows-msvc
   ```
   The binary lands at `target/x86_64-pc-windows-msvc/release/writ.exe`.

4. Training run using pre-compiled bytecode (NOT .writ source — keeps profile focused on VM dispatch):
   ```bash
   ./target/x86_64-pc-windows-msvc/release/writ.exe run benchmark/cases/fib/fib.writc
   ```
   Expected output: `102334155`. Do NOT record timing — the instrumented binary is 2-3x slower.

5. Verify .profraw files were created:
   ```bash
   ls pgo-data/*.profraw
   ```
   At least one `default_<hash>.profraw` file must exist.

6. Merge profiles:
   ```bash
   LLVM_PROFDATA="$HOME/.rustup/toolchains/nightly-x86_64-pc-windows-msvc/lib/rustlib/x86_64-pc-windows-msvc/bin/llvm-profdata.exe"
   "$LLVM_PROFDATA" merge -o "$PGODIR/merged.profdata" "$PGODIR"
   ```

7. Optimized rebuild with profile data:
   ```bash
   RUSTFLAGS="-Cprofile-use=$PGODIR/merged.profdata -Cllvm-args=-pgo-warn-missing-function" \
     cargo build --release --target x86_64-pc-windows-msvc
   ```

8. Measure fib(40) with the PGO-optimized binary — 3 cold runs, record all three times and the median:
   ```bash
   time ./target/x86_64-pc-windows-msvc/release/writ.exe run benchmark/cases/fib/fib.writc
   time ./target/x86_64-pc-windows-msvc/release/writ.exe run benchmark/cases/fib/fib.writc
   time ./target/x86_64-pc-windows-msvc/release/writ.exe run benchmark/cases/fib/fib.writc
   ```
   Each run must produce output `102334155` (VERIFY-01).

9. Record results:
   - Run 1 time, Run 2 time, Run 3 time
   - Median of the three
   - Delta from Phase 80 baseline (43.765s) in seconds and percentage
   - VERIFY-04 assessment: median < 30s? YES/NO

10. Run test suite to confirm correctness (VERIFY-02) — without RUSTFLAGS, without --target:
    ```bash
    cargo test --release
    ```
    Must pass with zero failures.

11. Verify zero warnings (VERIFY-03):
    ```bash
    cargo build --release 2>&1 | grep "^warning" | head -5
    ```
    Must produce no output.

IMPORTANT: Paths in RUSTFLAGS MUST be absolute. Use `$(pwd)/pgo-data` expanded before passing to RUSTFLAGS. The `--target x86_64-pc-windows-msvc` flag ensures build scripts are not compiled with PGO flags.

   **get_or_alloc_field_info**(&mut self, module_idx, typedef_idx, field_offset, heap, modules) -> HeapRef:
   - Cache key: (module_idx, absolute_field_idx) where absolute_field_idx = typedef's field_list start + field_offset
   - Allocate FieldInfo heap object: type_key = (0u32 << 16) | 13 (FieldInfo TypeDef index), field_count = 3
   - Field 0 (name): read from FieldDefRow.name via string_heap
   - Field 1 (declared_type): call `self.get_or_alloc_type()` to get a Type HeapRef for the field's declared type. For simplicity, use the type_blob to determine the type — OR use Value::Void as a placeholder if type resolution is too complex (full type resolution comes in Phase 106)
   - Field 2 (is_mutable): `Value::Bool((field_def.flags & 0x01) == 0)` — 0x01 is FIELD_FLAG_READONLY
   - Insert into field_cache and return

   **get_or_alloc_method_info**(&mut self, module_idx, method_idx, heap, modules) -> HeapRef:
   - Cache key: (module_idx, method_idx)
   - Allocate MethodInfo heap object: type_key = (0u32 << 16) | 14, field_count = 3
   - Field 0 (name): read from MethodDefRow.name via string_heap
   - Field 1 (return_type): Value::Void placeholder (full type resolution in Phase 106)
   - Field 2 (parameters): allocate empty array for now (full param population in Phase 106 per research Open Question 3)
   - Insert into method_cache and return

   **get_or_alloc_attribute_info**(&mut self, name: &str, args: &[crate::domain::AttrValue], ordinal: usize, module_idx: usize, typedef_idx: usize, heap: &mut dyn GcHeap) -> HeapRef:
   - Cache key: (module_idx, typedef_idx, ordinal)
   - Allocate AttributeInfo heap object: type_key = (0u32 << 16) | 11, field_count = 2
   - Field 0 (name): alloc string from name
   - Field 1 (args): allocate an Array and populate with boxed AttrValue items. For each AttrValue, convert: AttrValue::String(s) -> alloc_string then Box, AttrValue::Int(i) -> Box(Value::Int(i)), AttrValue::Bool(b) -> Box(Value::Bool(b)), AttrValue::Float(f) -> Box(Value::Float(f))
   - Insert into attr_cache and return

   **get_or_alloc_contract_info**(&mut self, module_idx, contract_idx, heap, modules) -> HeapRef:
   - Cache key: (module_idx, contract_idx)
   - Allocate ContractInfo heap object: type_key = (0u32 << 16) | 12, field_count = 2
   - Field 0 (name): read from ContractDefRow.name via string_heap
   - Field 1 (type): Value::Void placeholder (full Type cross-ref in Phase 106)
   - Insert into contract_info_cache and return

   IMPORTANT: To recover module_idx/typedef_idx from a Type HeapRef, the ReflectionIndex needs a reverse map `type_reverse: FxHashMap<HeapRef, (usize, usize)>` — add this field to ReflectionIndex and populate it in get_or_alloc_type.

   **TypeMethods**: Similar pattern — iterate MethodDef rows for the typedef (using method_list range), allocate MethodInfo objects, return as Array.

   **TypeAttributes**: Call `domain.query_attributes_on(module_idx, typedef_idx)` to get attribute matches. For each, allocate AttributeInfo via `get_or_alloc_attribute_info`. Return as Array. This satisfies RT-05 (unified AttributeIndex with ModuleAttributeView).

   NOTE: `ctx` does not contain a reference to `domain` directly. The domain is on Runtime. To access attribute data, pass module data through — `modules[module_idx].module.attribute_defs` is accessible, or add a domain reference to ExecContext. Alternatively, pre-compute attribute data. Use `writ_module::tables::ATTR_OWNER_KIND_DECL` constant and filter `module.attribute_defs` directly, same logic as `Domain::query_attributes_on`.

   **TypeContracts**: Iterate ImplDef rows for the typedef, extract contract indices, allocate ContractInfo objects, return as Array.

   **TypeImplements**: Takes a Type HeapRef in r_base+1 (the contract type to check). Look up the typedef's impl_defs, check if any impl references the given contract. Return Value::Bool.

   **TypeGetName/TypeGetNamespace/TypeGetKind/TypeGetIsGeneric**: Read the field from the Type heap object at the appropriate field index (0=name, 1=namespace, 2=kind, 3=is_generic). Store in r_dst. Pattern: `ctx.heap.get_field(obj_href, field_idx)`.

   **FieldInfoGet**: Takes instance HeapRef in r_base+1. Recover field index from FieldInfo identity. Call `ctx.heap.get_field(instance_href, field_idx)`. Store result in r_dst.

   **MethodInfoGetName/GetReturnType/GetParameters**: Field reads from MethodInfo heap object (fields 0, 1, 2).

   **ParameterInfoGetName/GetType**: Field reads from ParameterInfo heap object (fields 0, 1).

   **AttributeInfoGetName/GetArgs**: Field reads from AttributeInfo heap object (fields 0, 1).

   **ContractInfoGetName/GetType**: Field reads from ContractInfo heap object (fields 0, 1).

**Step 1: Add emit_reflectable_auto_impl() to contracts.rs**

Add a new `pub(super)` function at the end of `writ-compiler/src/emit/collect/contracts.rs`:

```rust
/// Emit a synthetic Reflectable ImplDef + get_type() MethodDef for a user-defined type.
///
/// Called immediately after each collect_struct/class/entity/enum to satisfy COMP-03.
/// The MethodDef is parented to the TypeDef so finalize() groups it correctly.
/// The body (TYPEOF + RET) is emitted separately in emit_all_bodies.
pub(super) fn emit_reflectable_auto_impl(
    typedef_handle: TypeDefHandle,
    def_id: DefId,
    builder: &mut ModuleBuilder,
) -> MethodDefHandle {
    // Reflectable contract token: ContractDef at 0-based index 18, 1-based row 19.
    // TableId::ContractDef = 10. This is spec-locked (CONTEXT.md locked decision).
    let reflectable_contract_token = MetadataToken::new(10, 19);

    // Encode sig blob for () -> Type (0 regular params, return = TypeRef to "Type").
    // Type TypeRef is registered as the 2nd add_type_ref call in collect_defs
    // (Range=row 1, Type=row 2). TypeRef blob tag = 0x30 per type_sig encoding.
    // Find the actual row by searching builder's type_refs for "Type".
    let type_typeref_row = builder.type_ref_row_by_name("Type")
        .expect("Type TypeRef must be registered before auto-impl emission");
    let mut sig_bytes = vec![0x00u8, 0x00]; // param_count = 0 (u16 LE, self not counted)
    sig_bytes.push(0x30); // TypeRef tag
    sig_bytes.extend_from_slice(&type_typeref_row.to_le_bytes());
    let sig_blob = builder.blob_heap_intern(&sig_bytes);

    // MethodDef: pub, not static, not mut_self, no hook
    let flags = method_flags(true, false, false, HookKind::None);
    let method_handle = builder.add_methoddef(
        Some(typedef_handle),  // parent = the TypeDef (critical for finalize sort)
        "get_type",
        sig_blob,
        flags,
        None,    // no DefId — synthetic method
        1,       // param_count = 1 (self)
    );

    // TypeDef token for the ImplDef.type_token field
    let type_token = MetadataToken::new(1, (typedef_handle.0 + 1) as u32); // TableId::TypeDef=1, 1-based row

    // ImplDef: method_list = 0 (same as existing collect_impl pattern — the runtime
    // resolves methods via TypeDef.method_list, not ImplDef.method_list for user modules)
    builder.add_impl_def(type_token, reflectable_contract_token, 0, None);

    method_handle
}
```

**IMPORTANT**: The sig blob encoding above assumes TypeRef tag is `0x30` and uses u32 LE row index. Before implementing, verify the exact TypeRef blob format by reading `writ-compiler/src/emit/type_sig.rs` and checking how TypeRef return types are encoded in existing sig blobs (search for `0x30` or `TypeRef` in type_sig.rs). If the tag or encoding differs, match the existing pattern.

**IMPORTANT**: The function needs `builder.type_ref_row_by_name("Type")` and `builder.blob_heap_intern(&sig_bytes)`. Check if these helpers exist on ModuleBuilder:
- If `type_ref_row_by_name` does not exist, add it: scan `self.type_refs` for a TypeRef with name matching "Type" via string heap lookup, return the 1-based row index as u32.
- If `blob_heap_intern` does not exist, use the existing blob heap path: `self.blob_heap.intern(&sig_bytes)` — check the actual field name and method.

```rust
// Emit synthetic Reflectable get_type() bodies.
// Each auto-impl has a minimal body: alloc r0 (self), alloc r1 (Type), TYPEOF r1 type_idx, RET r1.
// These bodies have method_def_id=None, matching the MethodDef's def_id=None in the serializer's
// orphaned-body positional matching. They must be emitted BEFORE lambda bodies because
// reflectable MethodDefs are added during collect_defs (before pre_scan_lambdas) — so they
// appear first in the MethodDef table. Bodies must match this order. (lambdas are scanned before reflectable in the
// method_defs table because lambdas are added during pre_scan_lambdas before finalize,
// and reflectable MethodDefs are added during collect_defs inline with TypeDefs).
for &(type_def_id, _method_handle) in reflectable_infos {
    // Resolve the type_idx for this TypeDef (uses token_for_def, available post-finalize)
    let type_idx = builder.token_for_def(type_def_id)
        .map(|t| t.0)
        .unwrap_or(0);

    // Minimal body: r0=self (implicit), r1=TYPEOF result, RET r1
    let self_ty = crate::check::ty::Ty(0); // placeholder — self type doesn't affect IL execution
    let type_ty = crate::check::ty::Ty(0); // placeholder — Type return
    let mut reg_types = vec![self_ty, type_ty];
    let instructions = vec![
        Instruction::TypeOf { r_dst: 1, type_idx },
        Instruction::Ret { r_src: 1 },
    ];

    bodies.push(EmittedBody {
        method_def_id: None,
        instructions,
        reg_count: 2, // r0=self, r1=result
        reg_types,
        source_spans: Vec::new(),
        debug_locals: Vec::new(),
        pending_strings: Vec::new(),
        label_allocator: labels::LabelAllocator::new(),
    });
}
```

**CRITICAL ordering check**: The serializer matches orphaned bodies (method_def_id=None) to orphaned MethodDefs (def_id=None) in positional order. Lambda MethodDefs are added by `pre_scan_lambdas` which runs AFTER `collect_defs`. But wait — `pre_scan_lambdas` calls `builder.add_methoddef(...)` which appends to the method_defs Vec. The reflectable MethodDefs are added during `collect_defs` which runs BEFORE `pre_scan_lambdas`. So in the final method_defs table, reflectable MethodDefs appear BEFORE lambda MethodDefs.

Therefore, reflectable bodies must be emitted BEFORE lambda bodies in the bodies Vec. Move the reflectable body emission loop to BEFORE the lambda body emission loop in `emit_all_bodies`.

Verify this ordering by reading the `pre_scan_lambdas` call site in `emit/mod.rs` (line 100) — it runs after `collect_defs` (line 90).

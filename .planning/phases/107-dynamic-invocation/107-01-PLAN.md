```rust
IntrinsicId::FieldInfoGet => {
    let fi_href = helpers::extract_ref(&ctx.task.call_stack.last().unwrap().registers[r_obj as usize]);
    let instance_val = ctx.task.call_stack.last().unwrap().registers[r_base as usize + 1];
    let instance_href = match instance_val {
        Value::Ref(href) => href,
        Value::Struct { href, .. } => href,
        _ => return ExecutionResult::Crash("FieldInfo.get: instance argument is not a struct or ref".into()),
    };
    let (_module_idx, _typedef_idx, field_offset) = match ctx.reflection.lookup_field_identity(fi_href) {
        Some(id) => id,
        None => return ExecutionResult::Crash("FieldInfo.get: not a FieldInfo object".into()),
    };
    let val = ctx.heap.get_field(instance_href, field_offset).unwrap_or(Value::Void);
    let frame = ctx.task.call_stack.last_mut().unwrap();
    frame.registers[r_dst as usize] = val;
    ExecutionResult::Continue
}
```

   - Extract FieldInfo HeapRef from `r_obj` register
   - Extract instance from `r_base + 1` (handle both Value::Ref and Value::Struct)
   - Extract new value from `r_base + 2`
   - Call `ctx.reflection.lookup_field_identity(fi_href)` to get `(module_idx, typedef_idx, field_offset)`
   - Compute absolute field index: get TypeDef's `field_list` from `ctx.modules[module_idx].module.type_defs[typedef_idx]`, compute `abs_idx = (td.field_list.saturating_sub(1) as usize) + field_offset`
   - Read `flags` from `ctx.modules[module_idx].module.field_defs[abs_idx].flags`
   - If `flags & 0x01 != 0` (FIELD_FLAG_READONLY): read field name via `writ_module::heap::read_string()` from string_heap, return `ExecutionResult::Crash(format!("Reflection write to immutable field '{}'", name))`
   - Otherwise: call `ctx.heap.set_field(instance_href, field_offset, new_val)`, set `r_dst` to `Value::Void`, return `ExecutionResult::Continue`
   - On heap error: return `ExecutionResult::Crash(format!("FieldInfo.set: {}", e))`

2. Add `IntrinsicId::MethodInfoInvoke` arm in the MethodInfo section (after MethodInfoGetParameters):
   - Extract MethodInfo HeapRef from `r_obj` register
   - Extract instance from `r_base + 1`
   - Extract args array from `r_base + 2`
   - Call `ctx.reflection.lookup_method_identity(mi_href)` to get `(method_module_idx, method_idx)`
   - Validate method_idx is within bounds of `ctx.modules[method_module_idx].decoded_bodies`
   - Extract args from the array HeapRef via `ctx.heap.get_object(args_href)` matching `HeapObject::Array { elements, .. }` — clone elements into a Vec
   - Read `param_count` from `ctx.modules[method_module_idx].module.method_defs[method_idx].param_count`
   - If `args.len() != param_count as usize`: return `ExecutionResult::Crash(format!("MethodInfo.invoke: expected {} args, got {}", param_count, args.len()))`
   - Read `reg_count` from `ctx.modules[method_module_idx].decoded_bodies[method_idx].register_types.len()`
   - CRITICAL: Do NOT run an inner execution loop. Push a CallFrame onto `ctx.task.call_stack` using `CallFrame::with_pool(ctx.pool, method_idx, reg_count, r_dst)`. The frame must also store `method_module_idx` if the call frame tracks module index (check existing call frame usage in calls.rs)
   - Set r0 = instance_val (self parameter), r1..rN = args elements
   - Return `ExecutionResult::Continue` — the scheduler drives the callee frame. This ensures DYN-04 cooperative scheduling works naturally

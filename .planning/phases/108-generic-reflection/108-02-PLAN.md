**Test 1: test_is_generic_true_for_generic_typedef (GEN-01)**
- Create a module with a TypeDef "MyList" that has a GenericParam (owner=TypeDef token, owner_kind=0, ordinal=0, name="T")
- Add a method that calls `typeof(MyList)` then `Type.is_generic` (via CALL_VIRT on TypeGetIsGeneric contract)

**Test 2: test_is_generic_false_for_non_generic_typedef (GEN-01)**
- Create a module with a plain TypeDef "Point" (no generic params)
- Call `typeof(Point)` then `Type.is_generic`
- Assert the result is `Value::Bool(false)`

**Test 3: test_type_args_static_typeof (GEN-02)**
- Create a module with:
  - A TypeDef "Elem" (non-generic, user type)
  - A TypeSpec with signature `[0x20, 0x10, token_bytes...]` encoding Array<Elem>
  - A TYPEOF instruction using the TypeSpec token (table_id=4)
- Call `Type.type_args()` via CALL_VIRT on the TypeTypeArgs contract
- The returned Array should have length 1
- Read element 0 and verify it is a Type with name "Elem" (read field 0 from the Type href)

**Test 4: test_type_args_empty_for_non_generic (GEN-02)**
- Create a module with a plain TypeDef, call typeof(), then type_args()
- Assert the returned Array has length 0

**Test 5: test_method_info_attributes (GEN-03)**
- Create a module with a TypeDef "Widget" that has a method "update"
- Add an AttributeDef with owner pointing to the MethodDef (table_id=MethodDef=7, row_index=1-based method index), owner_kind != ATTR_OWNER_KIND_DECL
- Call typeof(Widget) -> Type.methods() -> get element 0 (MethodInfo) -> MethodInfo.attributes()
- Assert the returned Array has length 1
- Read element 0, verify AttributeInfo name matches the attribute name

**Test 6: test_field_info_attributes (GEN-03)**
- Create a module with a TypeDef "Item" that has a field "price"
- Add an AttributeDef with owner pointing to the FieldDef (table_id=FieldDef=5, row_index=1-based field index), owner_kind != ATTR_OWNER_KIND_DECL
- Call typeof(Item) -> Type.fields() -> get element 0 (FieldInfo) -> FieldInfo.attributes()
- Assert the returned Array has length 1
- Read element 0, verify AttributeInfo name matches

**Test 7: test_method_info_attributes_empty_when_none (GEN-03)**
- Create a module with a TypeDef that has a method with NO attributes on it
- Call MethodInfo.attributes()
- Assert the returned Array has length 0

**IMPORTANT:** For each test, check existing tests for the exact CALL_VIRT instruction encoding pattern. Each CALL_VIRT needs:
- `contract_key`: the contract_def token from virtual module
- `slot`: 0 (single-method contracts)
- `type_args_hash`: 0
- `r_dst`, `r_obj`, `r_args_start`, `r_args_count`

For discovering the correct contract_key values for the 3 new contracts, look at the virtual module contract ordering. The 3 new contracts are at indices 48, 49, 50 (0-based). The contract_key token is `(0u32 << 16) | (contract_0based_idx)`.

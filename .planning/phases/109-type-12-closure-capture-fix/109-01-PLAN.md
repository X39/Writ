<objective>
Fix TYPE-12: closures that reference outer-scope variables currently always have an empty capture list, so captured variables are never populated into the closure environment. This plan implements capture analysis in the type checker and capture-aware lambda body emission in the code generator.

Purpose: Closures are a core language feature. Without capture analysis, any closure referencing an outer variable silently reads uninitialized register 0 at runtime.

Output: Working closure capture end-to-end (checker populates captures, emitter writes SET_FIELD at call site, emitter reads GET_FIELD in closure body), validated by a new golden test.
</objective>

    **Part A: Add capture boundary tracking to LocalEnv** (env.rs)

    Add a `lambda_boundaries` field to `LocalEnv`:
    ```rust
    pub struct LocalEnv {
        scopes: Vec<Vec<(String, Ty, Mutability, SimpleSpan)>>,
        /// Stack of scope-depth markers where lambda boundaries start.
        /// When inside a lambda body, any variable resolved from a scope
        /// at depth < boundary is a capture.
        lambda_boundaries: Vec<usize>,
    }
    ```

    Add methods:
    ```rust
    /// Mark the current scope depth as a lambda boundary.
    /// Variables from scopes below this depth are captures.
    pub fn push_lambda_boundary(&mut self) {
        self.lambda_boundaries.push(self.scopes.len());
    }

    /// Remove the most recent lambda boundary.
    pub fn pop_lambda_boundary(&mut self) {
        self.lambda_boundaries.pop();
    }

    /// Look up a variable and determine if it crosses a lambda boundary.
    /// Returns Some((ty, mutability, span, is_capture)).
    pub fn lookup_with_capture(&self, name: &str) -> Option<(Ty, Mutability, SimpleSpan, bool)> {
        for (depth_rev, scope) in self.scopes.iter().rev().enumerate() {
            let depth = self.scopes.len() - 1 - depth_rev;
            for (n, ty, m, sp) in scope.iter().rev() {
                if n == name {
                    let is_capture = self.lambda_boundaries.last()
                        .map_or(false, |&boundary| depth < boundary);
                    return Some((*ty, *m, *sp, is_capture));
                }
            }
        }
        None
    }
    ```

    Update `new()` to initialize `lambda_boundaries: Vec::new()`.
    Update `Default` impl if needed.

    **Part B: Implement capture analysis in check_lambda** (lambda.rs)

    Replace the hardcoded `let captures = Vec::new();` (line 68) with actual capture tracking:

    1. Before pushing the lambda scope and checking the body, call `ctx.local_env.push_lambda_boundary()`.
    2. Add a `captured_vars: RefCell<Vec<Capture>>` or similar accumulator to CheckCtx, OR use a simpler approach: after checking the body, walk the TypedExpr body to collect all `TypedExpr::Var { name, .. }` references, then filter to those that are NOT lambda params and ARE in the enclosing LocalEnv.

    The simpler post-hoc approach is preferred (no need to modify CheckCtx or ident.rs):

    ```rust
    // After checking body, collect captures:
    let mut seen = std::collections::HashSet::new();
    let mut captures = Vec::new();
    let param_set: std::collections::HashSet<&str> = param_names.iter().map(|s| s.as_str()).collect();

    ```

    Add a helper function `collect_var_refs` that walks a `TypedExpr` recursively, and for each `TypedExpr::Var { name, ty, span, .. }`:
    - Skip if name is in `param_set` (it's a lambda parameter, not a capture)
    - Skip if name was already seen (dedup)
    - Call `ctx.local_env.lookup(name)` — if found, it's a local from the enclosing scope, so add `Capture { name, ty, mode: CaptureMode::ByValue, binding_span: span }`
    - If NOT found in local_env, it's a global/const/function — do not capture

    IMPORTANT: The walk happens AFTER `pop_scope()` for the lambda's own scope but BEFORE `pop_lambda_boundary()` — at this point the enclosing scope is visible but the lambda's params are gone. Actually, the simpler approach: do NOT use lambda_boundaries at all. Instead:

    1. Check body as currently done (params are in scope)
    2. Pop the lambda scope (line 62)
    3. Walk the typed body collecting all `Var` names
    4. For each var name that is NOT a param: look it up in `ctx.local_env` — if found, it's a capture from the enclosing function scope
    5. This works because after pop_scope, the lambda params are gone, but enclosing vars are still visible

    So Part A (LocalEnv changes) is NOT needed if using this approach. Only add `lambda_boundaries` if the simpler walk-based approach has issues. Start with the walk approach.

    The `collect_var_refs` function should handle all TypedExpr variants recursively (Block, If, Binary, Call, etc.) same as `collect_lambda_bodies_from_expr` in emit/body/mod.rs.

    In the lambda body emission loop (around line 633-656), change the code that currently creates a fresh `BodyEmitter` and ignores `_info`:

    New code — for each lambda body with captures, emit GET_FIELD instructions to load captured variables from the capture struct (passed as `self` in register 0) into named locals:

    ```rust
    let info = &lambda_infos[i];
    let mut emitter = BodyEmitter::new(builder, interner, struct_field_types);

    if !info.captures_info.is_empty() {
        // Register 0 is the capture struct instance (passed as `self`/target by the delegate)
        // Allocate r0 for the capture struct
        let closure_name = format!("__closure_{}", info.closure_idx);
        let r_self = emitter.alloc_reg(interner.void()); // r0 = capture struct ref

        // For each captured variable, emit GET_FIELD to load it from the capture struct
        for (cap_name, cap_ty) in &info.captures_info {
            let r_cap = emitter.alloc_reg(*cap_ty);
            let field_idx = builder.field_token_by_name_on_closure(&closure_name, cap_name).unwrap_or(0);
            emitter.emit(Instruction::GetField {
                r_dst: r_cap,
                r_obj: r_self,
                field_idx,
            });
            emitter.locals.insert(cap_name.clone(), r_cap);
        }
    }

    let r = expr::emit_expr(&mut emitter, lambda_body);
    ```

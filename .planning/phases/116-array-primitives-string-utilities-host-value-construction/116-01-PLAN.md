<objective>
Wire array mutation methods (add, remove_at, insert, contains, slice) through the compiler type-checker and emitter so users can call them on any T[] value. The VM opcodes for add/remove_at/insert/slice already exist and are dispatched; only the compiler resolution is missing. A new ArrayContains opcode must be added end-to-end.

Purpose: Users currently cannot call arr.add(x), arr.remove_at(i), arr.insert(i, x), or arr.contains(x) — the type checker rejects them as unknown fields. The existing "push" alias must be renamed to "add" per spec.
Output: Fully working array dot-call methods with a golden test proving all five operations.
</objective>

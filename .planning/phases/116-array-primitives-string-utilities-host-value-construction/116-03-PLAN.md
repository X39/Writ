<objective>
Add a public `Runtime::construct_value(type_name, fields)` method that lets host Rust code create type-validated Writ struct/class values, and add an `ExternHandler::ImmediateWithHeap` variant that provides heap access to immediate extern handlers so they can construct values during handler execution.

Purpose: Game engines embedding Writ need to construct Writ values from Rust code (e.g., creating NPC state structs). Currently there is no public API for this. HOST-01/02/03 require type-validated construction with clear error messages.
Output: Public API on Runtime for host value construction + ImmediateWithHeap handler variant + integration tests.
</objective>

    **Step 3 — Implement on_extern_call_with_heap for ExternHost:**

    In `extern_registry.rs`, implement the method for `ExternHost`:
    ```rust
    fn on_extern_call_with_heap(
        &mut self,
        id: RequestId,
        extern_idx: u32,
        args: &[Value],
        heap: &mut dyn GcHeap,
    ) -> Option<HostResponse> {
        let idx = Self::decode_extern_idx(extern_idx);
        if let Some(handler) = self.handlers.get_mut(&idx) {
            match handler {
                ExternHandler::ImmediateWithHeap(f) => {
                    Some(match f(args, heap) {
                        Ok(val) => HostResponse::Value(val),
                        Err(msg) => HostResponse::Error(msg),
                    })
                }
                _ => None, // fall through to on_request for Immediate/Deferred
            }
        } else {
            None
        }
    }
    ```

    NOTE: `decode_extern_idx` is a helper on ExternHost — verify its signature. It extracts the string key from the integer extern index. Read how the existing `on_request` impl uses it.

    **Step 4 — Wire dispatch loop in dispatch/mod.rs:**

    // For ExternCall, try heap-aware dispatch first
    if let HostRequest::ExternCall { extern_idx, args, .. } = &request {
        if let Some(response) = host.on_extern_call_with_heap(id, *extern_idx, args, &mut *ctx.heap) {

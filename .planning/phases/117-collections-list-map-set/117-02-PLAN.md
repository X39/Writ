**List<T>** (COLL-01) — required API per REQUIREMENTS.md: `add(item)`, `get(i)`, `set(i,v)`, `len()`, `remove_at(i)`, `contains(item)`. No push/pop:
```writ
pub class List<T> {
    items: T[]
}

impl List<T> {
    pub fn new() -> List<T> {
        new List<T> { items: [] }
    }

    pub fn add(mut self, item: T) {
        self.items.add(item);
    }

    pub fn get(self, index: int) -> T {
        self.items[index]
    }

    pub fn set(mut self, index: int, item: T) {
        self.items[index] = item;
    }

    pub fn len(self) -> int {
        self.items.len()
    }

    pub fn remove_at(mut self, index: int) {
        self.items.remove_at(index);
    }

    pub fn contains(self, item: T) -> bool {
        self.items.contains(item)
    }
}
```

**Map<K, V>** (COLL-02) — O(n) linear scan for v13.0 per REQUIREMENTS.md. Required API: `set(k,v)`, `get(k)`, `has(k)`, `remove(k)`, `len()`. Method named `has` (not `contains_key`):
```writ
pub class Map<K: Ord + Eq, V> {
    keys: K[],
    values: V[]
}

impl Map<K: Ord + Eq, V> {
    pub fn new() -> Map<K, V> {
        new Map<K, V> { keys: [], values: [] }
    }

    pub fn len(self) -> int {
        self.keys.len()
    }

    pub fn has(self, key: K) -> bool {
        let mut i: int = 0;
        while i < self.keys.len() {
            if self.keys[i] == key { return true; }
            i = i + 1;
        }
        false
    }

    pub fn get(self, key: K) -> V {
        let mut i: int = 0;
        while i < self.keys.len() {
            if self.keys[i] == key { return self.values[i]; }
            i = i + 1;
        }
        // Fallback — caller must check has() first
        self.values[0]
    }

    pub fn set(mut self, key: K, value: V) {
        let mut i: int = 0;
        while i < self.keys.len() {
            if self.keys[i] == key {
                self.values[i] = value;
                return;
            }
            i = i + 1;
        }
        self.keys.add(key);
        self.values.add(value);
    }

    pub fn remove(mut self, key: K) {
        let mut i: int = 0;
        while i < self.keys.len() {
            if self.keys[i] == key {
                self.keys.remove_at(i);
                self.values.remove_at(i);
                return;
            }
            i = i + 1;
        }
    }
}
```

Note: `keys()` and `values()` helper methods that return the backing arrays are intentionally omitted from the Map class definition — `keys` and `values` are field names, and returning them as methods would shadow the fields. If the compiler allows same-named methods, add them only if iteration tests need them in Plan 03.

**Set<T>** (COLL-03) — required API: `add(v)`, `remove(v)`, `contains(v)`, `len()`:
```writ
pub class Set<T: Eq> {
    items: T[]
}

impl Set<T: Eq> {
    pub fn new() -> Set<T> {
        new Set<T> { items: [] }
    }

    pub fn add(mut self, item: T) {
        if self.contains(item) { return; }
        self.items.add(item);
    }

    pub fn remove(mut self, item: T) {
        let mut i: int = 0;
        while i < self.items.len() {
            if self.items[i] == item {
                self.items.remove_at(i);
                return;
            }
            i = i + 1;
        }
    }

    pub fn contains(self, item: T) -> bool {
        self.items.contains(item)
    }

    pub fn len(self) -> int {
        self.items.len()
    }
}
```

**HashMap<K, V>** (COLL-05) — required API: `set(k,v)`, `get(k)`, `has(k)`, `remove(k)`, `len()`. Uses `K: Hashable` constraint. O(n) linear scan for Phase 117 (hash bucketing deferred):

```writ
pub class HashMap<K: Hashable, V> {
    keys: K[],
    values: V[]
}

impl HashMap<K: Hashable, V> {
    pub fn new() -> HashMap<K, V> {
        new HashMap<K, V> { keys: [], values: [] }
    }

    pub fn len(self) -> int {
        self.keys.len()
    }

    pub fn has(self, key: K) -> bool {
        let mut i: int = 0;
        while i < self.keys.len() {
            if self.keys[i] == key { return true; }
            i = i + 1;
        }
        false
    }

    pub fn get(self, key: K) -> V {
        let mut i: int = 0;
        while i < self.keys.len() {
            if self.keys[i] == key { return self.values[i]; }
            i = i + 1;
        }
        self.values[0]
    }

    pub fn set(mut self, key: K, value: V) {
        let mut i: int = 0;
        while i < self.keys.len() {
            if self.keys[i] == key {
                self.values[i] = value;
                return;
            }
            i = i + 1;
        }
        self.keys.add(key);
        self.values.add(value);
    }

    pub fn remove(mut self, key: K) {
        let mut i: int = 0;
        while i < self.keys.len() {
            if self.keys[i] == key {
                self.keys.remove_at(i);
                self.values.remove_at(i);
                return;
            }
            i = i + 1;
        }
    }
}
```

Note: HashMap uses linear scan identical to Map for Phase 117. The `K: Hashable` constraint is declared to prove constraint enforcement compiles. True O(1) hash-based bucketing is a future optimization per RESEARCH.md Open Question 4.

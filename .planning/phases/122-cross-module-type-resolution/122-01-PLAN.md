```rust
fn decode_type_from_blob(
    blob: &[u8],
    cursor: &mut usize,
    lib_type_def_id_map: &FxHashMap<u32, DefId>,
    interner: &mut TyInterner,
) -> Ty
```

This must mirror `writ-compiler/src/emit/type_sig.rs` encoding:
- `0x00` => `TyKind::Void`, `0x01` => `TyKind::Int`, `0x02` => `TyKind::Float`, `0x03` => `TyKind::Bool`, `0x04` => `TyKind::String`, `0x05` => `TyKind::AnyEntity`
- `0x10` => read u32 (1-based TypeDef row), look up in `lib_type_def_id_map` to get DefId, then create the appropriate `TyKind::Struct/Class/Entity/Enum/Contract(def_id)` based on the TypeDef's kind. If not found in map, return `TyKind::Error`.
- `0x12` => read u16, `TyKind::GenericParam(idx as usize)`
- `0x20` => recursively decode element type, `TyKind::Array(elem)`
- `0x30` => read u32 blob_offset, decode function sig from that sub-blob (u16 param_count, param types, ret type), `TyKind::Func { params, ret }`
- For unknown tags, return `TyKind::Error`.

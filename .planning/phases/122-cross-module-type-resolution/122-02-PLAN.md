**Part C: Virtual module injection (XMOD-03)**

The `writ-runtime` crate exposes `build_writ_runtime_module()` which returns a `Module` containing contracts (Add, Sub, Iterable, Iterator, etc.) and a few type stubs. Currently, prelude contracts are recognized by name in the scope chain via `PRELUDE_CONTRACT_NAMES` returning `LookupResult::PreludeContract(name)` without a DefId.

To make virtual module types resolvable through the same DefMap mechanism:
1. In `writ-compiler/src/resolve/inject_library.rs`, add:
```rust
pub fn inject_virtual_module(
    def_map: &mut super::def_map::DefMap,
) {
    let virtual_module = writ_runtime::build_writ_runtime_module();
    inject_module_types(&[&virtual_module], def_map);
}
```
Wait -- `writ-compiler` cannot depend on `writ-runtime` (circular dependency risk). Check the Cargo.toml dependencies.

Alternative approach: The virtual module injection should happen at the call site level. In `resolve::resolve()`, the caller (pipeline or compile_source) constructs the virtual module and passes it as part of `library_modules`. OR: the resolve function internally calls `inject_module_types` with a virtual module that is constructed within `writ-compiler` or passed in.

Actually, per RESEARCH: "the `writ-runtime` virtual module is a `Module` object; same injection function works." The cleanest approach: the callers of `resolve()` (pipeline, compile_source, compile_with_libraries) build the virtual module and include it in `library_modules`. But this requires `writ-compiler` to depend on `writ-runtime` or for the caller to handle it.

Check `writ-cli/Cargo.toml` -- it depends on both `writ-compiler` and `writ-runtime`. So `writ-cli` can call `writ_runtime::build_writ_runtime_module()` and include it in `library_modules`.

For `compile_source` and `compile_with_libraries` (in `writ-compiler/src/lib.rs`), `writ-compiler` likely does NOT depend on `writ-runtime`. Check `writ-compiler/Cargo.toml` to confirm.

**Decision:** Virtual module injection for XMOD-03 happens at the CLI level (in `cmd_build`/`cmd_run`). For `compile_source`/`compile_with_libraries`, the caller is responsible for passing virtual module if needed. The test helpers in `coll_integration_tests.rs` will pass the virtual module explicitly.

//! Cross-module type resolution integration tests (XMOD-06).

/// Helper: compile source to bytes.
fn compile(src: &str) -> Vec<u8> {
    let src_static: &'static str = Box::leak(src.to_string().into_boxed_str());
    writ_compiler::compile_source(src_static).expect("compile failed")
}

/// Helper: compile source with library modules.
fn compile_with_libs(src: &str, libs: &[&writ_module::Module]) -> Result<Vec<u8>, String> {
    let src_static: &'static str = Box::leak(src.to_string().into_boxed_str());
    writ_compiler::compile_with_libraries(src_static, libs)
}

/// XMOD-01/02: User code can reference a struct type from a library module.
#[test]
fn xmod_type_reference() {
    // Compile a library defining a struct
    let lib_src = r#"
        pub struct Point { x: int, y: int }
        pub fn make_point() -> Point {
            let p: Point = new Point { x: 1, y: 2 };
            return p;
        }
    "#;
    let lib_bytes = compile(lib_src);
    let lib_module = writ_module::Module::from_bytes(&lib_bytes).unwrap();

    // Compile user code that references the library type
    let user_src = r#"
        pub fn main() -> int {
            let p: Point = make_point();
            return p.x;
        }
    "#;
    let result = compile_with_libs(user_src, &[&lib_module]);
    assert!(result.is_ok(), "expected compile success, got: {:?}", result.err());
}

/// XMOD-06: Method call on library type type-checks.
#[test]
fn xmod_method_call() {
    let lib_src = r#"
        pub class Counter { value: int }
        impl Counter {
            pub fn increment(mut self) {
                self.value = self.value + 1;
            }
            pub fn get(self) -> int {
                return self.value;
            }
        }
        pub fn new_counter() -> Counter {
            return new Counter { value: 0 };
        }
    "#;
    let lib_bytes = compile(lib_src);
    let lib_module = writ_module::Module::from_bytes(&lib_bytes).unwrap();

    let user_src = r#"
        pub fn main() -> int {
            let c: Counter = new_counter();
            c.increment();
            return c.get();
        }
    "#;
    let result = compile_with_libs(user_src, &[&lib_module]);
    assert!(result.is_ok(), "expected compile success, got: {:?}", result.err());
}

/// XMOD-06: Field access on library struct.
#[test]
fn xmod_field_access() {
    let lib_src = r#"
        pub struct Pair { first: int, second: string }
    "#;
    let lib_bytes = compile(lib_src);
    let lib_module = writ_module::Module::from_bytes(&lib_bytes).unwrap();

    let user_src = r#"
        pub fn main() -> int {
            let p: Pair = new Pair { first: 42, second: "hello" };
            return p.first;
        }
    "#;
    let result = compile_with_libs(user_src, &[&lib_module]);
    assert!(result.is_ok(), "expected compile success, got: {:?}", result.err());
}

/// XMOD-06: Type-not-found error when referencing non-existent library type.
#[test]
fn xmod_type_not_found_error() {
    let lib_src = r#"
        pub struct RealType { x: int }
    "#;
    let lib_bytes = compile(lib_src);
    let lib_module = writ_module::Module::from_bytes(&lib_bytes).unwrap();

    let user_src = r#"
        pub fn main() -> int {
            let x: NonExistentType = ???;
            return 0;
        }
    "#;
    let result = compile_with_libs(user_src, &[&lib_module]);
    assert!(result.is_err(), "expected compile failure for unknown type");
    let err = result.unwrap_err();
    // The error should mention the unknown type name
    assert!(
        err.contains("NonExistentType") || err.contains("unknown") || err.contains("resolution"),
        "expected error about unknown type, got: {}", err
    );
}

/// XMOD-02: Generic library type reference (e.g., List<int>).
#[test]
fn xmod_generic_type_reference() {
    let lib_src = r#"
        pub class Box<T> { value: T }
        impl<T> Box<T> {
            pub fn get(self) -> T {

        pub fn main() -> int {
            let b: Box<int> = new Box<int> { value: 42 };
            return b.get();
        }
    "#;
    let result = compile_with_libs(user_src, &[&lib_module]);
    assert!(result.is_ok(), "expected compile success, got: {:?}", result.err());
}

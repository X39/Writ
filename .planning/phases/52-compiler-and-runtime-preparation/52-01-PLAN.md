<objective>
Fix SourceSpan line numbers and extend DebugLocal with type information in the compiled .writil binary format.

Purpose: The compiled .writil currently hardcodes line=0/column=0 in SourceSpan entries and DebugLocal lacks type information. Both are blocking for LSP (hover, go-to-def) and DAP (breakpoints, variable display). This plan fixes both in one pass since they share the same emit/serialize code path.

Output: Format version 4 binary with correct 1-based line:col in SourceSpan, DebugLocal carrying type_ref, and disassembler showing .locals section + source location comments.
</objective>

    - Thread `sources` through to `serialize::serialize` (add parameter there too)
    - Inside serialize, for each method body: find the matching source text by FileId, call `build_line_starts(src)` to build the line-offset table, pass it to `build_source_spans`

Create `writ-dap/src/server.rs` with a `DapServer` struct. This is the main DAP protocol handler.

**DapServer struct:**
```rust
use dap::prelude::*;
use std::io::{BufRead, Write};

pub struct DapServer<I: BufRead, O: Write> {
    server: Server<I, O>,
    // State set during configuration phase (before launch)
    pending_breakpoints: Vec<(String, Vec<u32>)>,  // (source_path, lines)
    // State set after launch
    runtime: Option<Runtime<DebugHost>>,
    source_path: Option<String>,
    module: Option<Module>,
    task_id: Option<TaskId>,
    launched: bool,
    // Whether to stop on entry (configurable via launch args)
    stop_on_entry: bool,
}
```

**Main loop — `pub fn run(&mut self)`:**

Loop calling `self.server.poll_request()`. Match on `req.command`:

1. **`Command::Initialize(args)`**:
   - Respond with `ResponseBody::Initialize(Some(Capabilities { supports_configuration_done_request: Some(true), supports_step_back: Some(false), .. }))`.
   - Immediately send `Event::Initialized` after the response.

2. **`Command::SetBreakpoints(args)`**:
   - Extract source path from `args.source.path` (or `args.source.name`).
   - Extract requested lines from `args.breakpoints` (each has a `line` field).
   - If module is loaded (post-launch): resolve via `debug_host.breakpoints.set_breakpoints(&lines)`, respond with resolved breakpoints (verified=true, line=resolved_line).
   - If module NOT loaded (pre-launch): store in `pending_breakpoints`, respond with all breakpoints as unverified (verified=false).
   - Build response: `ResponseBody::SetBreakpoints(SetBreakpointsResponse { breakpoints: vec![...] })`.
   - Each breakpoint in response: `dap::types::Breakpoint { id: Some(bp.id), verified: true/false, line: Some(bp.line), source: Some(source.clone()), .. }`.

3. **`Command::ConfigurationDone(_)`**:
   - Respond with `ResponseBody::ConfigurationDone`.
   - (No action needed — launch is triggered by Launch command.)

4. **`Command::Launch(args)`**:
   - Extract `program` from launch args (the .writ file path). The `args` is a `serde_json::Value` map. Read `args["program"]` as a string.
   - Extract optional `stopOnEntry` boolean from args (default false).
   - Call `compile_and_load(&program_path)`. On error, respond with `req.error(&error_string)` and return.
   - Build `BreakpointTable::new(&module)`.
   - Build `DebugHost::new(breakpoint_table)`.
   - Build `Runtime` via `RuntimeBuilder::new(module).with_host(debug_host).build()`.
   - Find the `main` export: search `module.export_defs` for `item_kind == 0` and name == `"main"`. The `item` field's method index (0-based from token) is the entry method. Call `runtime.spawn_task(method_idx, vec![])`.
   - Resolve any `pending_breakpoints` now that the module is loaded: for each `(path, lines)`, call `runtime.host_mut().breakpoints.set_breakpoints(&lines)`. Send `Event::Breakpoint` updates for each resolved breakpoint (verified=true with actual line).
   - Respond with `ResponseBody::Launch`.
   - If `stop_on_entry`: send `Event::Stopped(StoppedEventBody { reason: "entry", thread_id: Some(1), all_threads_stopped: Some(true), .. })`.
   - If NOT stop_on_entry: run execution loop (see `run_until_stop` helper below).

5. **`Command::Threads(_)`**:
   - Respond with a single thread: `Thread { id: 1, name: "main".to_string() }`.
   - (Phase 56 will add per-task threads.)

6. **`Command::StackTrace(args)`**:
   - Get `task_id` from stored state.
   - Get call stack frames via `runtime.call_stack_frames(task_id)`.
   - For each `(method_idx, pc)` (iterate in REVERSE for top-to-bottom display):
     - Resolve method name: `module.method_defs.get(method_idx)` -> `read_string(&module.string_heap, method_def.name)`. Fallback to `format!("method_{}", method_idx)`.
     - Resolve source location: find the largest `span.pc <= pc` in `module.method_bodies[method_idx].source_spans`. Get `(line, col)`.
     - Build `StackFrame { id: frame_index as i64, name, source: Some(Source { path: Some(source_path.clone()), name: Some(filename), .. }), line: line as i64, column: col as i64, .. }`.
   - Respond with `ResponseBody::StackTrace(StackTraceResponse { stack_frames, total_frames: Some(count as i64) })`.

7. **`Command::Disconnect(_)`**:
   - Respond with `ResponseBody::Disconnect`.
   - Break out of the main loop.

8. **`Command::Scopes(_)` / `Command::Variables(_)`**:
   - Respond with empty scopes/variables (Phase 56 implements these).
   - `ResponseBody::Scopes(ScopesResponse { scopes: vec![] })`.
   - `ResponseBody::Variables(VariablesResponse { variables: vec![] })`.

9. **Default** (unhandled commands):
   - Respond with `req.error("not supported")`.

**Helper: `run_until_stop(&mut self)`** — runs the VM until a debug suspension or completion:
1. Call `runtime.resume_debug(task_id)` if task is suspended (clear previous suspend).
2. Loop: call `runtime.tick(0.0, ExecutionLimit::Instructions(1000))`.
3. After each tick, check `runtime.task_state(task_id)`:
   - If `Suspended` and `runtime.suspend_reason(task_id)` is `Some(Breakpoint{..})` or `Some(DebugStep{..})`:
     - Take the stop reason from `runtime.host_mut().take_pending_stop()`.
     - Send `Event::Stopped(StoppedEventBody { reason, thread_id: Some(1), all_threads_stopped: Some(true), hit_breakpoint_ids, .. })`.
     - Return (wait for next client command).
   - If `Completed` or all tasks completed:
     - Send `Event::Terminated(None)` and `Event::Exited(ExitedEventBody { exit_code: 0 })`.
     - Return.
   - If `Suspended` with `HostRequest` suspend reason:
     - Auto-confirm the request (DebugHost already does this via on_request) and continue the loop.
   - Otherwise: continue ticking.

Note on `ExecutionLimit::Instructions(1000)`: use a reasonable batch size (1000 instructions per tick) so the server remains responsive to debug events without per-instruction overhead on the tick loop. The `before_instruction` hook in DebugHost handles per-instruction breakpoint/step checks internally.

**Add step and continue command handlers to DapServer's main loop in server.rs:**

1. **`Command::Next(args)`** (Step Over):
   - Get current source location from `runtime.suspend_reason(task_id)` — extract `(line, method_idx)`.
   - Call `runtime.host_mut().set_step_over(task_id)`.
   - Respond with `ResponseBody::Next` (ACK immediately).
   - Call `run_until_stop()` — runs VM until DebugHost stops at next line at same/lower depth.

2. **`Command::StepIn(args)`** (Step Into):
   - Get current source location from suspend_reason.
   - Call `runtime.host_mut().set_step_into(task_id, current_line, current_method)`.
   - Respond with `ResponseBody::StepIn`.
   - Call `run_until_stop()`.

3. **`Command::StepOut(args)`** (Step Out):
   - Call `runtime.host_mut().set_step_out(task_id)`.
   - Respond with `ResponseBody::StepOut`.
   - Call `run_until_stop()`.

4. **`Command::Continue(args)`** (Continue):
   - Call `runtime.host_mut().clear_step()`.
   - Respond with `ResponseBody::Continue(ContinueResponse { all_threads_continued: Some(true) })`.
   - Call `run_until_stop()`.

5. **`Command::Pause(args)`** (Pause — not stepping but needed for completeness):
   - Not implemented for Phase 55. Respond with `req.error("pause not supported")`.

Run the VSIX packaging pipeline from writ-vscode/:

1. Install npm dependencies:
   ```bash
   cd writ-vscode && npm install
   ```
   This installs `@vscode/vsce` (^3.0.0), `typescript` (^5.0.0), `@types/vscode` (^1.74.0), and `vscode-languageclient` (^9.0.0).
   If peer dependency errors block installation, retry with `npm install --legacy-peer-deps`.

2. Run the full package pipeline:
   ```bash
   npm run package
   ```
   This chains four steps:
   - `npm run compile` -> `tsc -b` -> compiles src/extension.ts to out/extension.js
   - `npm run build-binaries` -> `cargo build --release --manifest-path ../Cargo.toml -p writ-lsp -p writ-dap` -> produces target/release/writ-lsp.exe and target/release/writ-dap.exe
   - `npm run copy-binaries` -> `node scripts/copy-bins.js` -> copies binaries from target/release/ to bin/ (with .exe suffix on Windows)
   - `npx vsce package` -> produces writ-0.1.0.vsix in writ-vscode/

   The cargo build --release step may take 5-15 minutes. The `vsce package` step may emit a warning about the `writ-lang` publisher not being registered on the Marketplace — this is expected for v0.1.0 local distribution and does NOT block .vsix production.

3. If cargo build --release emits warnings (clippy lints, deprecations, unused imports): fix any that are blocking errors. Non-blocking warnings are acceptable for this build — note them in the commit message if present.

4. Verify the output file exists:
   ```bash
   ls -la writ-vscode/writ-0.1.0.vsix
   ```
   Expected: a file of approximately 5-15 MB (two Rust release binaries plus compiled JS and JSON assets).

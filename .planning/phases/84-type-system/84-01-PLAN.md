<objective>
Add TyKind::Contract as a first-class type variant, wire def_id_to_ty resolution, implement contract assignability in unification, and remove the E0122 error that blocks contract type annotations.

Purpose: This is the foundational change for contract-as-type support. Without TyKind::Contract, the compiler treats contract annotations as errors and resolves them to TyKind::Error, blocking all downstream features (method resolution, codegen, LSP).

Output: TyKind::Contract variant exists, contract type annotations compile, assignability is enforced, and the old E0122 guard is removed.

fn def_id_to_ty(def_id: DefId, def_map: &DefMap, interner: &mut TyInterner) -> Ty {
    let entry = def_map.get_entry(def_id);
    match entry.kind {
        DefKind::Struct | DefKind::ExternStruct => interner.intern(TyKind::Struct(def_id)),
        DefKind::Class | DefKind::ExternClass => interner.intern(TyKind::Class(def_id)),

        DefKind::Enum => interner.intern(TyKind::Enum(def_id)),
        // Contracts are not types — diagnostics are emitted at the call site (E0122).
        DefKind::Contract => interner.error(),
        _ => interner.error(),
    }
}

**4. check_stmt.rs — Remove E0122 guard, add assignability check (EMIT-03, TYPE-03, TYPE-04)**

Remove the entire E0122 block (lines 35-58) that checks for `DefKind::Contract` and emits `TypeError::ContractAsType`. Replace it with a contract assignability check.

After the existing `unify` call (around line 61-71), add a contract assignability check. When the annotated type is `TyKind::Contract(contract_def_id)` and the inferred type is a concrete nominal type (Struct/Class/Entity), check that the concrete type has an `impl Contract for Type` in `impl_index`:

```rust
// Contract assignability: if annotation is a contract type, check that the
// inferred type implements the contract (instead of requiring type equality).
if let TyKind::Contract(contract_def_id) = ctx.interner.kind(annotated_ty).clone() {
    // Skip if inferred type is Error (poison propagation)
    if !ctx.is_error(inferred_ty) {
        let concrete_def_id = match ctx.interner.kind(inferred_ty).clone() {
            TyKind::Struct(did) | TyKind::Class(did) | TyKind::Entity(did) => Some(did),
            TyKind::Contract(did) if did == contract_def_id => None, // same contract, already unified
            _ => {
                // Type cannot implement a contract — emit error
                let contract_entry = ctx.def_map.get_entry(contract_def_id);
                ctx.emit_error(TypeError::MissingContractImpl {
                    ty_name: ctx.display_ty(inferred_ty),
                    contract_name: contract_entry.name.clone(),
                    span: *name_span,
                    file: ctx.current_file,
                    suggestion: format!("add `impl {} for {}`", contract_entry.name, ctx.display_ty(inferred_ty)),
                });
                None
            }
        };
        if let Some(concrete_did) = concrete_def_id {
            let satisfies = ctx.type_env.impl_index.get(&concrete_did)
                .map(|impls| impls.iter().any(|e| e.contract_def_id == Some(contract_def_id)))
                .unwrap_or(false);
            if !satisfies {
                let contract_entry = ctx.def_map.get_entry(contract_def_id);
                ctx.emit_error(TypeError::MissingContractImpl {
                    ty_name: ctx.display_ty(inferred_ty),
                    contract_name: contract_entry.name.clone(),
                    span: *name_span,
                    file: ctx.current_file,
                    suggestion: format!("add `impl {} for {}`", contract_entry.name, ctx.display_ty(inferred_ty)),
                });
            }
        }
    }
    // Skip the normal unify call for contract annotations — assignability is checked above
} else if !ctx.is_error(annotated_ty) && !ctx.is_error(inferred_ty)
    && ctx.unify.unify(annotated_ty, inferred_ty, &mut ctx.interner).is_err() {
    // ... existing TypeMismatch error ...
}
```

IMPORTANT: The contract assignability check REPLACES the `unify` call for contract annotations. Restructure the if/else so that when annotated_ty is a Contract, we do assignability; otherwise, we do the existing unify path. The key insight is that unification is symmetric (A = B implies B = A) but assignability is directional (MyClass -> Movable is OK, but Movable -> MyClass is NOT).

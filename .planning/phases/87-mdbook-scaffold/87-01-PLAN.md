    Run: `cargo install mdbook --version 0.4.51`

    **Step 2: Strip H1 headers from all 70 spec files and promote headings**
    Create and run a Python script that processes all files in `language-spec/spec/*.md`:

    For each file:
    1. Read the first line. If it matches one of these three shared H1 patterns, process the file:
       - `# 1. Writ Language Specification`
       - `# Writ IL Specification`
       - `# Appendix`
    2. Remove the first line (the shared H1).
    3. Remove any blank lines immediately following (between the removed H1 and the next content).
    4. Promote all heading levels by one: `##` becomes `#`, `###` becomes `##`, `####` becomes `###`, etc.
       Use regex replacement: for any line starting with `##` (two or more `#`), remove one `#`.
    5. Write the file back in-place.

    Special case for `00_preamble.md`: After stripping the H1 (`# 1. Writ Language Specification`), the remaining content is a short preamble (Draft version, description, file extension). This has no H2 to promote — that is fine. The preamble content will be merged into `introduction.md` instead of having its own wrapper file.

    Special case for `01_table_of_contents.md`: This file should be processed by the H1 strip script like any other (strip the `# 1. Writ Language Specification` line), but it will NOT get a wrapper file — its content is a broken TOC with dead anchors. The language-ref landing page (in SUMMARY.md) will use `introduction.md` instead.

    After running the script, verify:

  <action>
    **Step 1: Install mdbook-admonish 1.20.0**
    Run: `cargo install mdbook-admonish --version 1.20.0`
    Verify with: `mdbook-admonish --version`

    **Step 2: Run mdbook-admonish install to inject CSS and book.toml config**
    Run from repo root: `mdbook-admonish install docs/`

    This command does two things automatically:
    1. Copies `mdbook-admonish.css` into the `docs/` directory
    2. Adds/updates `[preprocessor.admonish]` and `additional-css` entries in `docs/book.toml`

    After running, verify `docs/book.toml` now contains:
    - A `[preprocessor.admonish]` section with `command = "mdbook-admonish"`
    - An `assets_version` field (the exact value is set by the install command)
    - An `additional-css` entry in `[output.html]` referencing `mdbook-admonish.css`

    If `mdbook-admonish install` does not add the `additional-css` line automatically, manually add it to the `[output.html]` section:
    ```toml
    additional-css = ["mdbook-admonish.css"]
    ```

    **Step 3: Add admonish test content to introduction.md**
    Read the current `docs/src/introduction.md` and append the following admonish test blocks after the existing content:

    ```markdown

    ```admonish note
    Writ is a statically-typed game scripting language. This documentation covers the
    language reference, IL specification, and architecture overview.
    ```

    ```admonish warning
    Writ is pre-1.0. Breaking changes may occur between versions.
    ```

    ```admonish tip
    Start with the [Overview](language-ref/overview.md) chapter for a high-level introduction to the language.
    ```
    ```

    (Note: the triple-backtick fences are literal Markdown fenced code blocks using the `admonish` info string.)

    **Step 4: Build and verify**
    Run `mdbook build docs/` — must exit 0.
    Then verify:
    - `docs/target/book/index.html` exists
    - `grep -q "admonish" docs/target/book/index.html` — admonish content is in the rendered HTML
    - `docs/mdbook-admonish.css` exists
    - `docs/book.toml` contains `[preprocessor.admonish]`
  </action>

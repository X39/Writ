    **File 2: `docs/src/getting-started/hello-world.md`** (per START-02)

    Write a Hello World walkthrough with these sections:
    - `# Hello World` as H1
    - Brief intro: "Create your first Writ program"
    - `## Writing the Program` — show creating a file `hello.writ` with this exact content:
      ```writ
      entity Narrator {}

      pub fn main() {
          let speaker: Entity = Entity.getOrCreate<Narrator>();
          ::say(speaker, "Hello, World!");
      }
      ```
      Explain briefly: `entity Narrator {}` defines a speaker entity, `Entity.getOrCreate<Narrator>()` obtains an instance, `::say()` is a builtin dialogue function that displays text.
    - `## Compiling` — run `writ compile hello.writ` which produces `hello.writc`
    - `## Running` — run `writ run hello.writc` which outputs `[say] <entity@0>: Hello, World!`
    - Use an admonish note explaining that `[say]` is the CLI host's annotation format; real game hosts provide their own display. The speaker shows as `<entity@0>` because Entity values display as handles in the CLI.
    - Use an admonish warning: `writ run` takes a compiled `.writc` file, not a `.writ` source file. Always compile first.

    **File 3: `docs/src/getting-started/cli-reference.md`** (per START-03)

    Write a CLI reference documenting ALL 6 subcommands. Per the CONTEXT.md locked decision: "Every subcommand documented with all flags." Use the verified CLI facts from the RESEARCH.md (originally sourced from `writ-cli/src/main.rs`).

    Structure:
    - `# CLI Reference` as H1
    - Brief intro: "The `writ` command-line tool provides subcommands for creating, building, compiling, assembling, disassembling, and running Writ programs."
    - One H2 section per subcommand in this order: `## writ new`, `## writ build`, `## writ compile`, `## writ assemble`, `## writ disasm`, `## writ run`
    - Each section has: description, usage line, flags/arguments table, example invocation
    - Flag details (verified from source, copy exactly):
      - `writ new <name>`: positional name (required), alphanumeric/hyphens/underscores. Creates writ.toml, .gitignore, sources/main.writ, bin/configuration/
      - `writ build [path]`: path (default `.`), `--release`, `--debug` (default), `--name <name>`. Output: `build/<profile>/<module_name>.writc`
      - `writ compile <input>`: input (required), `-o`/`--output <path>`. Always debug info. Rejects directories with message pointing to `writ build`
      - `writ assemble <input>`: input (required, or `-` for stdin), `-o`/`--output <path>`
      - `writ disasm <input>`: input (required), `--verbose`
      - `writ run <input>`: input (required .writc), `--entry <name>` (default `main`), `--interactive`, `--verbose`
  </action>

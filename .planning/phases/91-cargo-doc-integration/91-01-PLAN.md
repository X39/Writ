  <action>
    1. Add the following block to the END of the root `Cargo.toml` (after `[profile.release]`):

    ```toml
    [workspace.lints.rustdoc]
    # Suppress warn-by-default rustdoc lints — pre-1.0 project, docs are
    # a best-effort baseline. Re-enable per-crate when docs are polished.
    broken_intra_doc_links = "allow"
    private_intra_doc_links = "allow"
    invalid_html_tags = "allow"
    bare_urls = "allow"
    redundant_explicit_links = "allow"
    invalid_codeblock_attributes = "allow"
    invalid_rust_codeblocks = "allow"
    ```

    2. Add `[lints]` section with `workspace = true` to each of the 10 member crate Cargo.toml files. Append at the END of each file:

    ```toml

    [lints]
    workspace = true
    ```

    The 10 member crates are: writ-assembler, writ-cli, writ-compiler, writ-dap, writ-diagnostics, writ-golden, writ-lsp, writ-module, writ-parser, writ-runtime.

    IMPORTANT: Use `[workspace.lints.rustdoc]` in the root, NOT `[lints.rustdoc]` — the root is a virtual workspace manifest. Use `[lints]` with `workspace = true` in members, NOT `[lints.rustdoc]` — lint inheritance is all-or-nothing per crate.

    3. After editing all files, run `cargo check` to verify the lint config is syntactically valid (Cargo will error on invalid lint table structure).
  </action>

    - `cargo check --workspace` succeeds (exit code 0)
  </acceptance_criteria>
  <done>Workspace lint configuration committed. All 10 member crates inherit rustdoc lint suppression from workspace root. cargo check passes.</done>

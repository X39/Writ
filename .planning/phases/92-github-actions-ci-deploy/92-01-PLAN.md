  <action>
Create `.github/workflows/docs.yml` with the following exact structure:

**Workflow metadata:**
- `name: Deploy docs to GitHub Pages`
- Trigger: `on: push: branches: [master]` and `workflow_dispatch`
- Top-level permissions: `contents: read`, `pages: write`, `id-token: write`
- Concurrency group: `group: "pages"`, `cancel-in-progress: false`

**Build job** (`build`, runs-on: ubuntu-latest):

Environment variables (at job level):
- `MDBOOK_VERSION: "0.4.51"` (CI-04: pinned version)
- `MDBOOK_ADMONISH_VERSION: "1.20.0"`

Steps in this exact order:
1. `actions/checkout@v4`
2. **Install mdBook and mdbook-admonish** — download pre-built binaries (not cargo install, per CI-04):
   ```
   mkdir -p bin
   curl -sSL "https://github.com/rust-lang/mdBook/releases/download/v${MDBOOK_VERSION}/mdbook-v${MDBOOK_VERSION}-x86_64-unknown-linux-gnu.tar.gz" | tar -xz --directory=bin
   curl -sSL "https://github.com/tommilligan/mdbook-admonish/releases/download/v${MDBOOK_ADMONISH_VERSION}/mdbook-admonish-v${MDBOOK_ADMONISH_VERSION}-x86_64-unknown-linux-gnu.tar.gz" | tar -xz --directory=bin
   echo "$GITHUB_WORKSPACE/bin" >> $GITHUB_PATH
   ```
3. **Install Rust toolchain** — `dtolnay/rust-toolchain@stable` (matches existing project pattern)
4. **Cache cargo** — `actions/cache@v4` with:
   - path: `~/.cargo/registry`, `~/.cargo/git`, `target`
   - key: `${{ runner.os }}-cargo-docs-${{ hashFiles('**/Cargo.lock') }}`
   (Use `-cargo-docs-` key prefix to avoid colliding with the vscode-extension.yml cache which uses `-cargo-`)
5. **Setup Pages** — `actions/configure-pages@v5` with `id: pages` (must be in build job before upload, per Pitfall 2)
6. **Build mdBook** — `cd docs && mdbook build` (must run from docs/ directory per Pitfall 1; book.toml has build-dir=target/book so output is docs/target/book/)
7. **Build cargo doc** — `cargo doc --workspace --no-deps` (output to target/doc/)
8. **Inject API redirect** — `cp docs/api-redirect.html target/doc/index.html` (per Phase 91 decision; cargo issue #1016 means no root index.html exists)
9. **Merge cargo doc into book output** — `cp -r target/doc docs/target/book/api` (must be AFTER steps 6-8 and BEFORE step 10, per Pitfall 6)
10. **Upload artifact** — `actions/upload-pages-artifact@v3` with `path: docs/target/book` (the merged root; .nojekyll already present from mdBook auto-generation)

**Deploy job** (`deploy`, runs-on: ubuntu-latest):
- `needs: build`
- `environment: name: github-pages, url: ${{ steps.deployment.outputs.page_url }}`
- Single step: `actions/deploy-pages@v4` with `id: deployment`

Do NOT include:
- `cargo install mdbook` or `cargo install mdbook-admonish` (violates CI-04 pin requirement and adds 3-6 min build time)
- Manual `touch .nojekyll` step (mdBook 0.4.51 generates it automatically, per Pitfall 4)
- `RUSTDOCFLAGS` env var (not needed; workspace lint config from Phase 91 handles warnings)
- Pull request trigger (deploy should only happen on push to master, not on PRs)

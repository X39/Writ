    2. Create `writ-module/src/attr.rs` with the following contents:

       Tag constants (all `pub const`):
       - `ATTR_TAG_STRING: u8 = 0x01`
       - `ATTR_TAG_INT: u8 = 0x02`
       - `ATTR_TAG_BOOL: u8 = 0x03`
       - `ATTR_TAG_NAMED: u8 = 0x04`

       AttrValue enum (`#[derive(Debug, Clone, PartialEq)]`, `pub`):
       - `String(String)`
       - `Int(i64)`
       - `Bool(bool)`
       - `Named { name: String, value: Box<AttrValue> }`

       Public function `encode_attr_args(args: &[AttrValue]) -> Vec<u8>`:
       - Iterates args, calls internal `encode_attr_value(arg, &mut buf)` for each
       - Returns the buffer (empty Vec for empty slice)

       Internal function `encode_attr_value(val: &AttrValue, buf: &mut Vec<u8>)`:
       - AttrValue::String(s): push ATTR_TAG_STRING, push `(s.as_bytes().len() as u32).to_le_bytes()`, push `s.as_bytes()`
       - AttrValue::Int(n): push ATTR_TAG_INT, push `n.to_le_bytes()` (i64 LE, 8 bytes)
       - AttrValue::Bool(b): push ATTR_TAG_BOOL, push `if *b { 1u8 } else { 0u8 }`
       - AttrValue::Named { name, value }: push ATTR_TAG_NAMED, push `(name.as_bytes().len() as u32).to_le_bytes()`, push `name.as_bytes()`, recurse `encode_attr_value(value, buf)`

       Public function `decode_attr_args(blob: &[u8]) -> Result<Vec<AttrValue>, crate::error::DecodeError>`:
       - Walk with `cursor: usize = 0`, call `decode_one(blob, cursor)` returning `(AttrValue, bytes_consumed)` until cursor reaches end
       - Return Ok(vec![]) for empty blob

       Internal function `decode_one(blob: &[u8], pos: usize) -> Result<(AttrValue, usize), DecodeError>`:
       - Read tag byte at `blob[pos]`, advance 1
       - ATTR_TAG_STRING: read u32 LE at pos+1..pos+5 as `len`, read UTF-8 bytes at pos+5..pos+5+len, total consumed = 1+4+len
       - ATTR_TAG_INT: read i64 LE at pos+1..pos+9, total consumed = 9
       - ATTR_TAG_BOOL: read u8 at pos+1, 0=false else true, total consumed = 2
       - ATTR_TAG_NAMED: read u32 LE name_len at pos+1..pos+5, read name UTF-8 at pos+5..pos+5+name_len, then recurse decode_one at pos+5+name_len, total consumed = 5+name_len+inner_consumed
       - Unknown tag: return `Err(DecodeError::InvalidAttrTag(tag))`
       - Out-of-bounds reads: return `Err(DecodeError::BufferTooSmall)`

    3. Add `pub mod attr;` to `writ-module/src/lib.rs` after the existing `pub mod builder;` line. Also add `pub use attr::AttrValue;` to the re-exports block.

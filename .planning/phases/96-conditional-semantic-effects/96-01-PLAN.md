   pub conditional_fns: FxHashMap<DefId, String>,
   /// Maps conditional fn DefId -> fallback fn DefId (same name, same sig, no [Conditional]).

3. In `TypeEnv::build`, after the existing `deprecated_items` population pass, add a second pass to populate `conditional_fns`:
   - For each `AstDecl::Fn` in asts, call `env_build::find_attrs_for_entry` to get attrs.
   - Call `env_build::extract_conditional_name(&attrs)`. If `Some(cond_name)`, insert into `env.conditional_fns`.

4. In `TypeEnv::build`, after populating `conditional_fns`, add the fallback verification pass:
   - For each `(cond_def_id, cond_name)` in `conditional_fns`:
     - Get the conditional fn's entry from def_map, get its FnSig from `fn_sigs`.
     - Look up the overload set via `def_map.fn_overloads` (using the FQN or private key). If no overloads, check `def_map.by_fqn`.
     - Find a non-conditional fn in the set with matching signature (same param count, same param types, same return type).
     - If found, insert into `fallback_for_conditional`.
     - If NOT found, push E0009 diagnostic: `Diagnostic::error().with_code(E0009).with_message(format!("[Conditional(\"{cond_name}\")] function '{}' has no matching non-conditional fallback", entry.name)).with_labels(vec![Label::primary(entry.file_id, entry.name_span)])`.

5. In `writ-compiler/src/check/env_build.rs`, add `extract_conditional_name` (parallel to `extract_deprecated_msg`):
   ```rust
   pub(super) fn extract_conditional_name(attrs: &[AstAttribute]) -> Option<String> {
       for attr in attrs {
           if attr.name == "Conditional" {
               for arg in &attr.args {
                   if let AstAttributeArg::Positional(AstExpr::StringLit { value, .. }) = arg {
                       return Some(value.clone());
                   }
               }
           }
       }
       None
   }
   ```

IMPORTANT: The signature comparison for fallback matching must check: same number of params AND same types AND same return type. Use the existing `FnSig` struct fields. Generic params must also match count.

IMPORTANT: For the overload set lookup, the FQN key depends on whether the fn is namespaced. For public fns: `entry.namespace + "::" + entry.name` if namespace is non-empty, else just `entry.name`. For private fns: `name@file_id.0` format. Check `fn_overloads` first; if absent, the single fn lives in `by_fqn` (non-overloaded case where no fallback can exist unless it was just registered).

  <action>
Replace the stub body of `validate_speakers()` in validate.rs with the full implementation:

1. **Build singleton entity set:** Iterate all `(FileId, &Ast)` pairs, recursing into namespace blocks. For each `AstDecl::Entity(e)`, check if `e.attrs.iter().any(|a| a.name == "Singleton")`. Build a `HashSet<String>` of entity names that have [Singleton], and a separate `HashSet<String>` of ALL entity names (for existence checking).

2. **Walk function bodies for hoisted let pattern:** For each `AstDecl::Fn(f)` (recursing into namespace blocks and entity inherent_impl methods), walk `f.body` statements. For each `AstStmt::Let { name, name_span, value, .. }` where `name.starts_with('_')`:
   - Match `value` against `AstExpr::GenericCall { callee, type_args, args, .. }` where `args.is_empty()` and `type_args.len() == 1`
   - Match `callee` against `AstExpr::MemberAccess { object, field, .. }` where `field == "getOrCreate"`
   - Match `object` against `AstExpr::Ident { name: obj_name, .. }` where `obj_name == "Entity"`
   - Extract entity name from `type_args[0]` as `AstType::Named { name: entity_name, .. }`
   - If `entity_name` is NOT in the all-entities set: emit `ResolutionError::UnresolvedName { name: entity_name, file: file_id, span: *name_span, suggestion: None }`
   - Else if `entity_name` is NOT in the singleton set: emit `ResolutionError::InvalidSpeaker { name: entity_name, file: file_id, span: *name_span }`
   - Else: valid, no diagnostic

3. **Update the InvalidSpeaker error message** in error.rs to be more specific: change from `"speaker not found"` label to `"entity is not [Singleton]"` and update help text to `"add [Singleton] attribute to the entity declaration, or use a parameter-based speaker"`. This makes the message meaningful for the non-[Singleton] case (E0007), while non-existent speakers use the existing E0003 "cannot find name" message.

4. **Helper functions to add:**

   - `fn validate_speakers_in_items(items: &[AstDecl], file_id: FileId, singletons: &HashSet<String>, all_entities: &HashSet<String>, diags: &mut Vec<Diagnostic>)` -- recurses into namespace blocks and entity impls
   - `fn check_stmts_for_speakers(stmts: &[AstStmt], file_id: FileId, singletons: &HashSet<String>, all_entities: &HashSet<String>, diags: &mut Vec<Diagnostic>)` -- the hoisted let pattern matcher

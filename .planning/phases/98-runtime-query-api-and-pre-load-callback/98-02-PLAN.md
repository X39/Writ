    1. In `writ-runtime/src/domain.rs`, add a new struct `DomainAttributeMatch` (pub):
       ```rust
       #[derive(Debug, Clone)]
       pub struct DomainAttributeMatch {
           pub module_idx: usize,
           pub name: String,
           pub args: Vec<writ_module::attr::AttrValue>,
           pub owner: writ_module::token::MetadataToken,
           pub owner_kind: u8,
       }
       ```

    2. Add helper function (private) to decode a single AttributeDefRow into args:
       ```rust
       fn decode_row_args(module: &writ_module::Module, row: &AttributeDefRow) -> Vec<writ_module::attr::AttrValue> {
           if row.value == 0 {
               return vec![];  // null blob = no args
           }
           match writ_module::heap::read_blob(&module.blob_heap, row.value) {
               Ok(blob) => writ_module::attr::decode_attr_args(blob).unwrap_or_default(),
               Err(_) => vec![],  // gracefully handle malformed blob
           }
       }
       ```

    3. Add three query methods to `impl Domain`:

       a. `pub fn query_attributes(&self, attr_name: &str) -> Vec<DomainAttributeMatch>`
          - Iterate all modules (enumerate for module_idx)
          - For each module, iterate `module.module.attribute_defs`
          - Filter: `row.owner_kind != writ_module::tables::ATTR_OWNER_KIND_DECL`
          - Filter: `read_string(&module.module.string_heap, row.name) == Ok(attr_name)`
          - Decode args, build DomainAttributeMatch
          - Collect and return

       b. `pub fn query_attributes_on(&self, module_idx: usize, typedef_idx: usize) -> Vec<DomainAttributeMatch>`
          - Bounds check module_idx; return empty vec if out of range
          - Access `self.modules[module_idx].module`
          - Iterate attribute_defs, filter:
            - `row.owner_kind != ATTR_OWNER_KIND_DECL`
            - `row.owner.table_id() == TableId::TypeDef.as_u8()`
            - `row.owner.row_index() == Some((typedef_idx + 1) as u32)` (0-based to 1-based conversion)
          - Read name from string heap, decode args, build DomainAttributeMatch

       c. `pub fn query_attribute_value(&self, module_idx: usize, owner_token: MetadataToken, attr_name: &str) -> Option<Vec<writ_module::attr::AttrValue>>`
          - Bounds check module_idx; return None if out of range
          - Access `self.modules[module_idx].module`
          - Find first row in attribute_defs where:
            - `row.owner == owner_token`
            - `row.owner_kind != ATTR_OWNER_KIND_DECL`
            - `read_string(&module.string_heap, row.name) == Ok(attr_name)`
          - Decode and return Some(args), or None if not found

    4. Add re-export to `writ-runtime/src/lib.rs`:
       ```rust
       pub use domain::DomainAttributeMatch;
       ```

    Use `writ_module::tables::ATTR_OWNER_KIND_DECL` (not hardcoded 3).
    Use `writ_module::tables::TableId::TypeDef.as_u8()` for table comparison.
    row_index() is 1-based — convert typedef_idx (0-based) by adding 1.
    On decode failure, return empty vec / None — never panic.

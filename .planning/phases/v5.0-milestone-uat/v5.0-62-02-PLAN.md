**The core bug:** `SourceSpan.pc` stores byte offsets (from compiler serialization). `BreakpointTable` is built from these byte offsets. But `execute_one` passes `frame.pc` (instruction index) to `before_instruction` and `lookup_source_location`. Instruction index 5 != byte offset 23, so breakpoints never match and source line lookups are wrong.

**In writ-runtime/src/loader.rs:**

1. Add `byte_offsets` field to `LoadedModule`:
   ```rust
   pub struct LoadedModule {
       pub module: Module,
       pub decoded_bodies: Vec<Vec<Instruction>>,
       /// For each method body (parallel to decoded_bodies),
       /// maps instruction index -> byte offset in the original code stream.
       /// Used to translate VM instruction indices back to byte offsets for
       /// SourceSpan/breakpoint lookups.
       pub byte_offsets: Vec<Vec<u32>>,
       pub resolved_refs: ResolvedRefs,
   }
   ```

2. Change `decode_and_reindex` to also return the byte_offsets Vec. Change signature from:
   ```rust
   fn decode_and_reindex(raw_code: &[u8], method_idx: usize) -> Result<Vec<Instruction>, RuntimeError>
   ```
   To:
   ```rust
   fn decode_and_reindex(raw_code: &[u8], method_idx: usize) -> Result<(Vec<Instruction>, Vec<u32>), RuntimeError>
   ```
   Return the `byte_offsets` alongside instructions:
   ```rust
   Ok((instructions, byte_offsets))
   ```
   Also fix the empty-code early return:
   ```rust
   if raw_code.is_empty() {
       return Ok((Vec::new(), Vec::new()));
   }
   ```

3. Update `from_module` to collect byte_offsets:
   ```rust
   pub fn from_module(module: Module) -> Result<Self, RuntimeError> {
       let mut decoded_bodies = Vec::with_capacity(module.method_bodies.len());
       let mut byte_offsets_all = Vec::with_capacity(module.method_bodies.len());
       for (method_idx, body) in module.method_bodies.iter().enumerate() {
           let (instructions, byte_offsets) = decode_and_reindex(&body.code, method_idx)?;
           decoded_bodies.push(instructions);
           byte_offsets_all.push(byte_offsets);
       }
       Ok(Self {
           module,
           decoded_bodies,
           byte_offsets: byte_offsets_all,
           resolved_refs: ResolvedRefs::new(),
       })
   }
   ```

**In writ-runtime/src/dispatch/mod.rs:**

4. In `execute_one`, after extracting `let pc = frame.pc;`, compute the byte offset:
   ```rust
   let pc = frame.pc;

   // Translate instruction index to byte offset for source span and breakpoint lookups.
   // SourceSpan.pc and BreakpointTable store byte offsets, but frame.pc is an instruction index.
   let byte_pc = module.byte_offsets
       .get(method_idx)
       .and_then(|offsets| offsets.get(pc))
       .copied()
       .unwrap_or(0) as u32;
   ```

5. In the debug hook section, replace `pc as u32` with `byte_pc` for `lookup_source_location` and `before_instruction`:
   ```rust
   if host.debug_enabled() {
       let (line, col) = lookup_source_location(module, method_idx, byte_pc);
       let action = host.before_instruction(task.id, method_idx as u32, byte_pc, line, col);
       match action {
           DebugAction::Continue => {}
           DebugAction::Break => {
               task.suspend_reason = Some(SuspendReason::Breakpoint {
                   method_idx: method_idx as u32,

               // ...

           DebugAction::StepOver | DebugAction::StepInto | DebugAction::StepOut => {

                   pc: byte_pc,
                   line,

               });
               // ...
           }
           DebugAction::Disconnect => {}
       }
   }
   ```
   Keep `frame.pc += 1;` using instruction index (that's correct — instruction stepping is index-based). Only the debug reporting/lookup uses byte offsets.

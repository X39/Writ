<objective>
Fix two related DAP debugger bugs: (1) breakpoints set on early lines in a multi-function file
snap to the wrong function, and (2) step-into doesn't work for function calls.

Root cause: The block expression emitter in `expr/mod.rs` treats the last statement as a "tail
expression" and calls `emit_expr` directly, bypassing `emit_stmt`. Since `emit_stmt` is the only
place that pushes source span entries (line 35 of `stmt.rs`), the tail expression gets NO source
span. For single-statement functions like `fn test() { log::info("test"); }`, this means the entire
function has zero source spans. For multi-statement functions, the last statement has no source span.

Consequences:
- Functions with zero source spans have no valid breakpoint lines. Breakpoints on those lines snap
  to the nearest method that DOES have spans (wrong method, wrong line).
- Step-into lands at line 0 (unknown) because `lookup_source_location` returns (0,0) for methods
  with no spans.

Fix: Add a source span push for the tail expression before calling `emit_expr`, mirroring what
`emit_stmt` does on stmt.rs line 35.

Purpose: Make breakpoints and stepping work correctly across all functions.
Output: Fixed compiler, regression tests.
</objective>

  <name>Task 1: Fix source span emission for tail expressions in block emitter</name>
  <files>writ-compiler/src/emit/body/expr/mod.rs</files>
  <action>
In the Block expression handler (around line 103-143 of `expr/mod.rs`), find the code path
where the last statement is treated as a tail expression (the `if let TypedStmt::Expr { expr:
last_expr, .. } = last` branch, around line 119-125).

Currently this code calls `emit_expr(emitter, last_expr)` directly WITHOUT pushing a source
span first. This is the root cause — `emit_stmt` on stmt.rs:35 pushes a source span, but
this path bypasses emit_stmt entirely.

**Fix**: Before the `emit_expr(emitter, last_expr)` call on line 125, add a source span push
using the STATEMENT's span (from the `TypedStmt::Expr` wrapping the expression). This mirrors
exactly what `emit_stmt` does:

```rust
// In the `if let TypedStmt::Expr { expr: last_expr, .. } = last` branch:
if let crate::check::ir::TypedStmt::Expr { expr: last_expr, span, .. } = last {
    for stmt in rest {
        emit_stmt(emitter, stmt);
    }
    // Push source span for the tail expression (mirrors emit_stmt line 35).
    // Without this, functions where the last/only statement is the tail
    // have no source span, breaking breakpoints and stepping.
    let instr_idx = emitter.instructions.len() as u32;
    emitter.source_spans.push((instr_idx, *span));
    emit_expr(emitter, last_expr)
}
```

Note: destructure `span` from the `TypedStmt::Expr` pattern — the current pattern is
`TypedStmt::Expr { expr: last_expr, .. }` which discards the span. Change to
`TypedStmt::Expr { expr: last_expr, span, .. }`.

# Quick Task 260320-28c: Investigation Summary

**Task:** Figure out why writ code with fib/main using Option types does not compile
**Result:** Not a compiler bug — user syntax error

## Finding

The code fails at the **parse stage** with:

```
found 'KwReturn' at 51..57 expected 'LBrace' (and other operators)
```

The issue is this construct:

```writ
if n <= 1
    return n;
```

Writ requires braces around `if` bodies (like Rust). The fix is:

```writ
if n <= 1 {
    return n;
}
```

## Verification

With braces added, the entire program compiles successfully through all 5 stages (parse → lower → resolve → typecheck → emit), including:

- `int?` type annotation (Option type)
- `Some(fib(20))` and `None` construction
- `.unwrap()` method call
- `n!` (unwrap-or-panic operator)
- `.is_none()` and `.is_some()` method calls
- `for i in [2..n]` range loop
- `log::info(...)` with string interpolation
- Variable shadowing (`let n` declared twice)

## Conclusion

No compiler changes needed. All Option-related features work correctly.

# Quick Task 260320-3wc: Fix SetField using raw MetadataToken as field index

## Task 1: Fix compiler to emit 0-based local field indices

**Files:** `writ-compiler/src/emit/module_builder.rs`, `writ-assembler/src/assembler.rs`, `writ-assembler/src/disassembler.rs`

**Action:** Change `field_token_by_name` and `field_token_by_name_on_closure` to return 0-based local field indices instead of MetadataTokens (which have table prefix 0x05). Update assembler/disassembler to treat field_idx as plain integer.

**Root cause:** `field_token_by_name` returned `MetadataToken::new(TableId::FieldDef, row_idx).0` (e.g., 0x05000001 = 83886081), but the runtime's `exec_set_field`/`exec_get_field` use field_idx directly as an array index into the struct's fields vec.

**Verify:** `cargo test --package writ-cli --test e2e_compile_tests`

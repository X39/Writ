# Quick Task 260324-74b: Fix impl contract bugs

**Date:** 2026-03-24
**Status:** Complete

## Bugs Fixed

### Bug 1: E0123 diagnostic showed "impl#0" instead of target type name
**Root cause:** `validate_contract_impls()` in `env.rs` used `impl_entry_entry.name` which is the synthetic impl block name (`"impl#0"`), not the target type name.
**Fix:** Use `target_def_id` (the `impl_index` key) to look up the actual type name from DefMap.
**File:** `writ-compiler/src/check/env.rs:337`

### Bug 2: Runtime crash when calling impl methods with `self` on class instances
**Root cause:** `fn_param_map` in `collect_impl` (contracts.rs) filtered out `SelfParam`, so the body emitter never pre-allocated r0 for self. For empty method bodies like `fn foo(self){}`, this resulted in `reg_count=0`. The caller passed `argc=1` (including self), causing an out-of-bounds access in `calls.rs:36`.
**Fix:** Include self as the first entry in `fn_param_map` when `has_self` is true, so the body emitter naturally allocates r0 for self.
**File:** `writ-compiler/src/emit/collect/contracts.rs:143-156`
